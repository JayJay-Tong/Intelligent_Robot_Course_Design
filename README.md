# 智能机器人课程设计

**基于 STM32F103C8T6 的迷宫智能机器人**

---

## 项目简介

本项目为智能机器人课程设计，目标是设计并实现一款能够在迷宫中自主导航的智能小车。小车以 STM32F103C8T6 微控制器为核心，通过安装在车头左右两侧的红外避障传感器感知迷宫墙壁，采用右手法则导航算法实现迷宫内的自主行驶，最终到达迷宫出口或指定灭火点。

---

## 硬件平台

| 组件 | 型号/规格 |
|------|----------|
| 主控芯片 | STM32F103C8T6（Blue Pill，72MHz，Cortex-M3） |
| 电机驱动 | L298N 双路 H 桥驱动模块 |
| 驱动电机 | 两路无编码器减速直流电机 |
| 传感器 | 红外避障传感器 ×2（左：PA11，右：PA12） |
| 控制接口 | 按键启动（PA15） |
| 电源 | 7.4V 锂电池 + 降压至 5V/3.3V |
| 固件库 | STM32 HAL 库（CubeMX 生成） |
| 开发板 | STM32F103 扩展板 |

## 快速上手

### 1. 环境准备

- 安装 **Keil MDK-ARM v5**（μVision5）
- 安装 **ST-Link 驱动**（用于下载和调试）
- 克隆或下载本项目到本地

### 2. 打开工程

打开 `script/Project.uvprojx`，Keil 将自动加载所有源文件。

### 3. 编译

点击菜单 **Project → Build Target**（或按 `F7`），确认 0 Error，0 Warning。

### 4. 硬件连接

按照 [output/软硬件详细设计.md](output/软硬件详细设计.md) 中的接线表连接所有硬件：

- 左红外传感器 DO → **PA11**
- 右红外传感器 DO → **PA12**
- L298N IN1~IN4 → **PB6/PB7/PB8/PB9**
- 电机共地，确保 STM32 GND = L298N GND

### 5. 下载固件

通过 ST-Link V2 连接开发板，点击 **Flash → Download**（或按 `F8`）烧录固件。

### 6. 运行

上电后按下启动按键，机器人开始自主导航迷宫。

## 核心算法：右手法则

机器人根据左右两个红外传感器的输出，实时决策行驶方向：

迷宫中正常行驶时两侧均有墙壁（传感器均检测到障碍）；当某侧墙壁消失时说明出现路口，向该侧转弯。

| 左传感器 | 右传感器 | 执行动作 |
|---------|---------|---------|
| 有墙（0） | 有墙（0） | 直行（正常走廊） |
| 无墙（1） | 有墙（0） | 向左转（400ms，左侧出现路口） |
| 有墙（0） | 无墙（1） | 向右转（400ms，右侧出现路口） |
| 无墙（1） | 无墙（1） | 向右转（400ms，T形/十字路口优先右转） |

## 引脚分配

| 功能 | STM32 引脚 | 模式 |
|------|-----------|------|
| 左电机正转 | PB6 | TIM4_CH1 PWM（占空比 0~99） |
| 左电机反转 | PB7 | TIM4_CH2 PWM（占空比 0~99） |
| 右电机正转 | PB8 | TIM4_CH3 PWM（占空比 0~99） |
| 右电机反转 | PB9 | TIM4_CH4 PWM（占空比 0~99） |
| 左红外传感器 | PA11 | GPIO 输入（上拉，低=有墙） |
| 右红外传感器 | PA12 | GPIO 输入（上拉，低=有墙） |
| 启动按键 | PA15 | GPIO 输入（上拉，低=按下） |
| 调试串口 TX | PA9 | USART1 TX（115200 baud） |
