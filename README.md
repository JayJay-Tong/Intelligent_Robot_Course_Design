# 智能机器人课程设计

**基于 STM32F103C8T6 的迷宫智能机器人**

---

## 项目简介

本项目为智能机器人课程设计，目标是设计并实现一款能够在迷宫中自主导航的智能小车。小车以 STM32F103C8T6 微控制器为核心，依靠车头左右两侧的红外避障传感器贴墙巡线，并用前向 HC-SR04 超声波传感器检测死路。当一侧 IR 持续丢墙时判定为路口，执行"预进 + 旋转对齐 + 再旋转"的 C 型转弯；当前方距离过近时判定为死路，原地掉头 180°，并在掉头后跳过紧邻的第一个路口直行通过，从而实现迷宫内的自主行驶。

> 工程中还包含 HMC5883L 电子罗盘（I²C2）等开源驱动文件，当前固件版本未启用（见 `script/Src/main.c` 顶部注释 "纯 IR 导航 (无磁力计)"），保留作为后续扩展接口。

## 硬件平台

| 组件 | 型号/规格 |
|------|----------|
| 主控芯片 | STM32F103C8T6（Blue Pill，外部 8MHz 晶振 + PLL ×9 = 72MHz，Cortex-M3） |
| 电机驱动 | L298N 双路 H 桥驱动模块 |
| 驱动电机 | 两路无编码器减速直流电机 |
| 侧墙传感器 | 红外避障传感器 ×2（左：PA11，右：PA12，上拉输入，低=有墙） |
| 前向测距 | HC-SR04 超声波模块（TRIG=PB1，ECHO=PA0，TIM2 输入捕获） |
| 控制接口 | 按键启动（PA15，上拉输入，低=按下） |
| 状态指示 | 板载 LED（PC13） |
| 调试接口 | USART1（PA9 TX，115200 baud，printf 重定向） |
| 预留模块 | HMC5883L 电子罗盘（I2C2，当前固件未启用） |
| 电源 | 7.4V 锂电池 + 降压至 5V/3.3V |
| 固件库 | STM32 HAL 库（CubeMX 生成） |
| 开发板 | STM32_10B 小车底板 + STM32F103 扩展板 |

## 快速上手

### 1. 环境准备

- 安装 **Keil MDK-ARM v5**（μVision5）
- 安装 **ST-Link 驱动**（用于下载和调试）
- 克隆或下载本项目到本地

### 2. 打开工程

打开 `script/MDK-ARM/script.uvprojx`，Keil 将自动加载所有源文件（HAL 库工程）。

### 3. 编译

点击菜单 **Project → Build Target**（或按 `F7`），确认 0 Error，0 Warning。

### 4. 硬件连接

按照 [output/软硬件详细设计.md](output/软硬件详细设计.md) 中的接线表连接所有硬件：

- 左红外传感器 DO → **PA11**，右红外传感器 DO → **PA12**
- HC-SR04：TRIG → **PB1**，ECHO → **PA0**
- 启动按键 → **PA15**
- L298N IN1~IN4 → **PB6/PB7/PB8/PB9**
- 电机共地，确保 STM32 GND = L298N GND

### 5. 下载固件

通过 ST-Link V2 连接开发板，点击 **Flash → Download**（或按 `F8`）烧录固件。

### 6. 运行

上电后 PC13 LED 闪烁等待启动按键；按下 **PA15** 后 LED 常灭，机器人开始自主导航迷宫。

## 核心算法：IR 巡墙 + 超声波死路掉头

机器人主循环（`script/Src/main.c`）每 30ms (`LOOP_MS`) 读取一次左右 IR 与超声波距离，按以下优先级决策：

1. **死路掉头**：超声波距离 `dist < FRONT_STOP_MM`（100mm）时，停车并原地差速旋转 180°（`u_turn_180`，按 `U_TURN_180_MS` 定时），随后置位 `skip_next_gap`，使掉头后遇到的第一个路口直行通过（避免立刻折返进入来时的路口）。
2. **两侧均有墙**：直行（`BASE_SPEED`），并清零验证计数器。
3. **单侧丢墙**（路口候选）：先以 `±VERIFY_DIFF` 差速向丢墙一侧微调贴墙；若连续 `VERIFY_THRESH`（7 次，约 210ms）仍未找回该侧墙壁，判定为真实路口，触发 **C 型转弯**（`c_turn`）：
   - 预进 `APPROACH_MS`（车身越过墙角）；
   - `spin_until_both_walls` 原地转向缺口一侧，直到两侧 IR 同时检测到墙（对齐新走廊）；
   - 前进 `C_FWD_MS` 穿过路口；
   - 再次 `spin_until_both_walls` 完成第二个 90°。
4. **两侧均丢墙**（开阔地，理论上少见）：直行。

掉头后第一个被确认的路口不会触发 C 型转弯，而是进入 `in_skip_pass` 直行状态，直到两侧 IR 重新同时检测到墙壁才恢复正常巡墙逻辑。

## 引脚分配

| 功能 | STM32 引脚 | 模式 |
|------|-----------|------|
| 左电机正转 | PB6 | TIM4_CH1 PWM（20kHz，占空比 0~99） |
| 左电机反转 | PB7 | TIM4_CH2 PWM（20kHz，占空比 0~99） |
| 右电机正转 | PB8 | TIM4_CH3 PWM（20kHz，占空比 0~99） |
| 右电机反转 | PB9 | TIM4_CH4 PWM（20kHz，占空比 0~99） |
| 左红外传感器 | PA11 | GPIO 输入（上拉，低=有墙） |
| 右红外传感器 | PA12 | GPIO 输入（上拉，低=有墙） |
| 启动按键 | PA15 | GPIO 输入（上拉，低=按下） |
| HC-SR04 TRIG | PB1 | GPIO 推挽输出 |
| HC-SR04 ECHO | PA0 | TIM2_CH1 输入捕获（1µs 分辨率，超时 ~65.5ms） |
| 板载 LED | PC13 | GPIO 输出（低电平点亮，启动前闪烁/运行中常亮） |
| 调试串口 TX | PA9 | USART1 TX（115200 baud，printf 重定向） |
