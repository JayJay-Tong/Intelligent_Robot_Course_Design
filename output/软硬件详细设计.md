#### 红外避障传感器（主用，×2）

## 2 系统硬件连接

### 2.1 硬件连接总图说明

```
                    ┌─────────────────────┐
                    │   STM32F103C8T6     │
                    │   （蓝色小板）       │
    左红外 DO ──────│PA11          PB6────│──── L298N IN1（左电机+）
    右红外 DO ──────│PA12          PB7────│──── L298N IN2（左电机-）
    按键    S1 ─────│PA15          PB8────│──── L298N IN3（右电机+）
    3.3V   ─────────│3V3           PB9────│──── L298N IN4（右电机-）
    GND    ─────────│GND               │
                    │  PA9(TX) PA10(RX)  │──── 调试串口（可选）
                    │         BOOT0=GND  │
                    └─────────────────────┘

    传感器电源：
    左红外 VCC ──── 3.3V
    左红外 GND ──── GND
    右红外 VCC ──── 3.3V
    右红外 GND ──── GND

    电机驱动：
    L298N VCC(12V) ── 7.4V 锂电池+
    L298N GND      ── 锂电池- = STM32 GND（共地）
    L298N 5V输出   ── STM32 5V/VIN（或单独稳压）
    L298N ENA      ── 5V（使能，常高）
    L298N ENB      ── 5V（使能，常高）
    L298N OUT1,OUT2── 左电机两端
    L298N OUT3,OUT4── 右电机两端
```

### 2.2 各模块详细接线表

**红外传感器接线：**

| 传感器引脚 | 连接到 | 说明 |
|-----------|--------|------|
| 左传感器 VCC | 3.3V | 电源正极 |
| 左传感器 GND | GND | 电源负极 |
| 左传感器 DO  | PA11 | 数字输出信号 |
| 右传感器 VCC | 3.3V | 电源正极 |
| 右传感器 GND | GND | 电源负极 |
| 右传感器 DO  | PA12 | 数字输出信号 |

**L298N电机驱动器接线：**

| L298N引脚 | 连接到 | 说明 |
|----------|--------|------|
| IN1 | PB6（TIM4_CH1） | 左电机正转PWM |
| IN2 | PB7（TIM4_CH2） | 左电机反转PWM |
| IN3 | PB8（TIM4_CH3） | 右电机正转PWM |
| IN4 | PB9（TIM4_CH4） | 右电机反转PWM |
| ENA | 5V | 左路使能（常高） |
| ENB | 5V | 右路使能（常高） |
| +12V | 7.4V（锂电池） | 电机电源 |
| GND | 系统GND | 共地 |
| 5V输出 | （可连接STM32 5V引脚） | 逻辑电源 |
| OUT1,OUT2 | 左电机 M1/M2 | 左轮电机 |
| OUT3,OUT4 | 右电机 M3/M4 | 右轮电机 |

### 2.3 电源系统连接

```
7.4V 锂电池
    │
    ├──────────────────── L298N VCC（电机电源）
    │
    └── 降压模块（7.4V→5V） ─── STM32 5V引脚（VIN）
                              │
                              └── STM32内部 LDO → 3.3V（芯片供电）
```

**注意事项：**
- 必须确保所有模块共地（STM32 GND = L298N GND = 传感器 GND）；
- L298N的5V输出引脚在电机电源≥7V时可输出稳定5V，可为STM32供电；
- 建议在电源输入端并联100μF电解电容，滤除电机启动时的电流冲击；
- 首次上电前，用万用表检查各电源轨电压。

## 3 编程环境及设置

### 3.1 开发工具

| 工具 | 版本/说明 |
|------|----------|
| 集成开发环境 | Keil MDK-ARM（μVision5）|
| 编译器 | ARM Compiler 5（ARMCC）|
| 调试器 | ST-Link V2 |
| 固件库 | STM32 HAL库（CubeMX 生成） |
| 代码生成 | STM32CubeMX（可选，已提供初始化代码）|
| 烧录软件 | Keil内置 / STM32 ST-LINK Utility |
| 串口调试 | XCOM / 串口助手（115200 baud，可选）|

### 3.2 Keil项目配置

**目标设备设置：**
- Device：STM32F103C8
- 内核：Cortex-M3
- Flash：64KB
- SRAM：20KB

**编译器设置：**
- 优化级别：Level 1（-O1）
- C标准：C99
- 定义宏：`STM32F103xB, USE_HAL_DRIVER`

**链接器设置：**
- 使用 Scatter File：`STM32F103C8Tx_FLASH.ld`（或 `.sct`）
- 起始地址：0x08000000（Flash）

**调试/下载设置：**
- 调试器：ST-Link Debugger
- 下载算法：STM32F10x 64kB Flash

### 3.3 项目文件结构（HAL库工程）

```text
script/
├── Src/                       # 用户可编辑源文件
│   ├── main.c                 # 主程序（迷宫导航逻辑）
│   ├── gpio.c                 # GPIO初始化（IR传感器/按键）
│   ├── tim.c                  # TIM2(输入捕获)/TIM4(PWM)初始化
│   ├── usart.c                # USART1串口初始化（调试用）
│   ├── stm32f1xx_it.c         # 中断服务程序

│   ├── main.h                 # 引脚宏定义（IR_LEFT/IR_RIGHT/KEY_START）
│   ├── gpio.h / tim.h / usart.h
│   └── stm32f1xx_hal_conf.h
└── Drivers/                   # STM32 HAL库（不需手动修改）
    ├── STM32F1xx_HAL_Driver/
    └── CMSIS/
```

## 5 开发调试步骤与时间安排

### 5.1 总体时间安排

| 时间 | 阶段 | 工作内容 |
|------|------|---------|
| 第1天 | 环境搭建 | 安装Keil、配置项目、建立工程框架 |
| 第2天 | 硬件连接 | 按接线图连接所有硬件，检查无误 |
| 第2~3天 | 驱动测试 | 分别测试PWM/电机、按键、传感器 |
| 第3~4天 | 避障基础 | 实现基础避障逻辑，在走廊中测试 |
| 第4~5天 | 迷宫算法 | 实现右手法则，在模拟迷宫中调参 |
| 第6天 | 完整测试 | 在正式迷宫中测试，精调参数 |
| 第7天 | 扩展功能 | 集成火焰传感器（可选） |
| 第7~8天 | 报告撰写 | 整理实验数据，撰写课程设计报告 |

### 5.2 分步调试方法

**Step 1：Keil工程配置（第1天）**

1. 打开 `script/` 下已有的 Keil 工程（HAL 库，CubeMX 生成）；
2. 确认宏定义 `STM32F103xB, USE_HAL_DRIVER` 已配置；
3. 配置 ST-Link 调试器（Utilities → ST-Link Debugger）；
4. 编译整个工程，确认 0 Error，0 Warning。

**Step 2：电机测试（第2天）**

```c
/* 在 main.c 的 USER CODE BEGIN 2 处添加以下临时测试代码 */
HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_1);
HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_3);
// 以 50% 占空比正转 2 秒
__HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_1, 50);
__HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_3, 50);
HAL_Delay(2000);
// 停止
__HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_1, 0);
__HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_3, 0);
HAL_Delay(1000);
```

**Step 3：传感器与按键测试（第3天）**

```c
/* 在 while(1) 中测试：用手遮挡传感器，通过串口或调试器观察变量值 */
GPIO_PinState L = HAL_GPIO_ReadPin(IR_LEFT_GPIO_Port,  IR_LEFT_Pin);
GPIO_PinState R = HAL_GPIO_ReadPin(IR_RIGHT_GPIO_Port, IR_RIGHT_Pin);
GPIO_PinState K = HAL_GPIO_ReadPin(KEY_START_GPIO_Port, KEY_START_Pin);
// 迷宫模式：GPIO_PIN_RESET(0)=有墙，GPIO_PIN_SET(1)=路口
// 用调试器在线查看 L/R/K 变量值验证逻辑
HAL_Delay(100);
```

**Step 5：避障集成测试（第3~4天）**
- 在直线走廊（约50cm宽）中测试；
- 用手在传感器前遮挡，观察机器人转向响应；
- 调整转向时间，使转向动作流畅。

**Step 6：迷宫适配调参（第5~6天）**
- 测量实际迷宫通道宽度和墙壁高度；
- 调整传感器灵敏度（电位器）；
- 在简单L形或T形路口中单独测试转弯；
- 记录最优速度和时间参数。

## 6 系统测试方案

### 6.1 单元测试

| 测试项 | 测试方法 | 通过标准 |
|--------|---------|---------|
| PWM输出测试 | 示波器测量PB6~PB9 | 频率20kHz，占空比随Compare值线性变化 |
| 电机正反转测试 | 单独设置各通道Compare值 | 每个电机能正转、反转、停止 |
| 传感器测试 | 手遮挡/开放传感器，调试器查看变量 | 遮挡返回RESET(0)，开放返回SET(1) |
| 按键测试 | 按下/松开PA15，调试器查看变量 | 按下返回RESET(0)，释放返回SET(1) |

### 6.2 集成测试

| 测试项 | 测试场景 | 通过标准 |
|--------|---------|---------|
| 直线行驶 | 无障碍直线走廊（1m） | 能沿直线行驶，偏差<5cm |
| 单侧避障 | 右侧放置障碍物 | 能自动向左避让 |
| 前方避障 | 正前方放置障碍物 | 能停止并转向 |
| L形迷宫 | 简单L形路径 | 能顺利转弯通过 |
| T形路口 | T形三叉路口 | 按右手法则选择正确方向 |

### 6.3 系统验收测试

**测试场景：** 标准迷宫（由课程提供的迷宫结构）

**测试流程：**
1. 将机器人放置在迷宫入口指定起始位置；
2. 按下启动按键；
3. 记录机器人从启动到到达出口的时间；
4. 观察是否有碰墙或卡死情况；
5. 重复测试5次，统计成功次数。

**评分标准：**
| 等级 | 标准 |
|------|------|
| 优秀 | 5次中≥4次成功，时间<2分钟 |
| 良好 | 5次中≥3次成功，时间<3分钟 |
| 合格 | 5次中≥2次成功，能完成大部分路径 |
| 不合格 | 无法独立通过迷宫 |
