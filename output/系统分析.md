## 1 系统概述

本课程设计的智能机器人系统以 **STM32F103C8T6** 微控制器为核心，搭配 **L298N 双路电机驱动模块** 驱动两路无编码器减速直流电机，利用安装在小车前方左右两侧的 **红外避障传感器** 感知迷宫墙壁，实现自主迷宫导航功能。

**选定题目：** 智能机器人走迷宫（可选扩展：迷宫灭火）

### 2.3 各子系统功能说明

#### 2.3.1 主控制器（STM32F103C8T6）

| 参数 | 说明 |
|------|------|
| 芯片型号 | STM32F103C8T6（Blue Pill） |
| 内核 | ARM Cortex-M3，72MHz主频 |
| Flash | 64KB（程序存储） |
| SRAM | 20KB（数据存储） |
| 工作电压 | 3.3V |
| GPIO | 37个可用IO |
| 定时器 | TIM1~TIM4（用TIM4输出PWM） |

主控制器负责读取传感器数据、执行迷宫导航算法、输出PWM控制信号。

#### 2.3.2 传感器系统

**红外避障传感器（×2）：**

| 项目 | 规格 |
|------|------|
| 类型 | 红外反射式，含发射管和接收管 |
| 检测距离 | 2~30cm（可调，通过电位器设置） |
| 输出信号 | 数字量：检测到障碍=低电平（0），无障碍=高电平（1） |
| 工作电压 | 3.3V~5V |
| 接线 | VCC、GND、DO（数字输出） |
| 连接引脚 | 左传感器→PA11，右传感器→PA12（上拉输入模式） |

**红外传感器工作原理：**
传感器发射红外光，当前方存在障碍物时，红外光被反射回来被接收管检测到，DO引脚输出低电平；无障碍物时接收不到反射光，DO引脚输出高电平。

#### 2.3.3 电机驱动系统

**L298N双路电机驱动器：**

| 项目 | 规格 |
|------|------|
| 驱动芯片 | L298N |
| 驱动电压 | 5V~46V |
| 驱动电流 | 最大2A（单路） |
| 控制信号 | 4路PWM输入（IN1~IN4） |
| 逻辑电压 | 5V（与STM32 3.3V兼容） |

**L298N控制逻辑：**

| IN1 | IN2 | 左电机状态 |
|-----|-----|-----------|
| PWM | 0   | 正转（前进） |
| 0   | PWM | 反转（后退） |
| 0   | 0   | 停止（滑行） |
| PWM | PWM | 制动（短路刹车） |

**TIM4 PWM配置：**

| 通道 | GPIO | 功能 |
|------|------|------|
| TIM4_CH1 | PB6 | 左电机正转（IN1） |
| TIM4_CH2 | PB7 | 左电机反转（IN2） |
| TIM4_CH3 | PB8 | 右电机正转（IN3） |
| TIM4_CH4 | PB9 | 右电机反转（IN4） |

PWM频率：72MHz / 36 / 100 = 20kHz，占空比0~100对应0%~100%。

## 3 工作原理分析

### 3.1 系统启动流程

```
上电
  │
  ▼
硬件初始化
  ├── PWM初始化（TIM4，PB6/7/8/9）
  ├── 红外传感器初始化（PA11、PA12，上拉输入）
  ├── 按键初始化
  └── OLED/LED初始化（可选）
  │
  ▼
等待按键触发（Key_GetNum() != 0）
  │
  ▼
进入主控制循环
```

### 3.2 迷宫导航控制原理

本系统采用**右手法则（Right Hand Rule）**实现迷宫自主导航。

**算法原理：**
迷宫中机器人正常行驶时，左右两侧均有墙壁（传感器均检测到障碍，输出0）。当某侧墙壁消失（传感器输出1）时，说明该侧出现了路口，机器人应向该侧转弯进入新通道。

本项目基于左右两个传感器的四状态决策：

```text
传感器状态 → 控制决策（有墙=0，无墙/路口=1）
─────────────────────────────────────────────────────────────
L=0（有墙）, R=0（有墙） → 前进（正常走廊）
L=1（无墙）, R=0（有墙） → 左转（左侧出现路口）
L=0（有墙）, R=1（无墙） → 右转（右侧出现路口）
L=1（无墙）, R=1（无墙） → 右转（T形/十字路口，优先右转）
```

### 3.3 电机控制原理

机器人底盘采用差速驱动（Differential Drive）方式：
- **前进：** 左轮和右轮以相同速度同向旋转；
- **左转：** 左轮减速或停止，右轮正常转速；
- **右转：** 右轮减速或停止，左轮正常转速；
- **原地旋转：** 左轮和右轮以相同速度反向旋转；
- **后退：** 左轮和右轮以相同速度反向旋转。

PWM占空比决定电机转速，占空比越高转速越快（0~100%）。

### 3.4 系统控制闭环

```
传感器检测（L, R）
       │
       ▼
算法决策（右手法则状态机）
       │
       ▼
PWM输出计算（速度+方向）
       │
       ▼
L298N驱动电机
       │
       ▼
小车运动（前进/转弯/停止）
       │
       └──────────── 反馈 ──────────────┘
                    （传感器持续检测）
```

## 4 完成迷宫导航任务的设计开发步骤

### 步骤一：需求分析与方案确定

1. 明确任务目标：小车在迷宫中自主导航，找到出口（或到达灭火点）；
2. 确定硬件配置：STM32F103C8T6 + 双红外传感器 + L298N + 双电机；
3. 选定导航算法：右手法则（简单可靠，适合固定迷宫结构）；
4. 明确验收标准：小车能在规定时间内通过迷宫，不碰撞墙壁。

### 步骤二：硬件搭建与连接

1. 按照原理图连接STM32与扩展板；
2. 连接L298N电机驱动器（IN1~IN4接PB6~PB9，使能端接高电平）；
3. 连接左红外传感器到PA11，右红外传感器到PA12；
4. 连接电源（锂电池→L298N→电机，稳压器→STM32）；
5. 检查连接是否正确，避免短路。

### 步骤三：基础驱动开发

1. 开发PWM模块（`PWM_Init`，配置TIM4）；
2. 开发电机控制封装（`robot.c`，实现前进/转弯/停止）；
3. 开发红外传感器读取模块（`Irobstacle.c`）；
4. 单模块测试：验证每个模块独立工作正常。

### 步骤四：基础功能测试

1. 测试电机正反转，调整速度参数（建议前进速度：60~80/100）；
2. 测试红外传感器，用手遮挡传感器验证输出逻辑；
3. 测试按键启动功能；
4. 测试简单避障：在直线走廊中验证传感器触发后的转向动作。

### 步骤五：迷宫导航算法集成

1. 编写主控逻辑（`main.c`）：实现四状态决策；
2. 调整转弯时间参数：
   - 在已知角度（90°）的走廊中测试，调整时间使转弯恰好90°；
   - 记录最优参数（转弯时间、速度）；
3. 在简单迷宫（2~3个路口）中验证算法正确性。

### 步骤六：完整迷宫测试与调参

1. 将机器人放入完整迷宫进行测试；
2. 观察失败位置，分析原因（速度过快、转弯不足/过大等）；
3. 针对性调参，重复测试；
4. 记录测试数据（成功次数、通过时间）。

### 步骤七：可选灭火功能集成

1. 增加火焰传感器读取模块；
2. 在主逻辑中添加火焰检测判断；
3. 检测到火焰时执行停车+指示动作（LED/蜂鸣器）；
4. 测试灭火功能在迷宫中的正确触发。

### 步骤八：系统验收与报告

1. 进行正式验收演示；
2. 记录系统性能数据；
3. 总结开发过程中遇到的问题及解决方案；
4. 撰写完整课程设计报告。

| 指标项目 | 目标值 | 说明 |
|----------|--------|------|
| 迷宫通过成功率 | ≥80% | 连续5次尝试中至少4次成功 |

## 6 系统局限性与改进方向

### 6.1 当前局限性

1. **无编码器：** 电机转速无反馈，转弯角度依赖延时控制，精度有限，在不同地面摩擦系数下表现不稳定；
2. **传感器数量少：** 仅有左右两个传感器，无法感知正前方中央的障碍物（正前方障碍需两传感器同时触发，存在盲区）；
3. **无地图记忆：** 机器人不记录已走路径，无法实现最短路径优化，可能重复探索已走区域；
4. **算法局限：** 右手法则对某些特殊迷宫结构（如孤岛型）可能无法找到出口。

### 6.2 改进方向

| 改进项目 | 技术方案 | 预期效果 |
|----------|----------|----------|
| 增加速度反馈 | 加装编码器，使用PID控制转速 | 提高转弯角度精度 |
| 增加前向感知 | 增加第三个红外传感器（前向中央）或超声波传感器 | 提前检测正前方障碍 |
| 增加地图记忆 | 利用SRAM存储路径信息，实现Flood Fill算法 | 最优路径导航 |
| 增加通信模块 | 加装蓝牙/Wi-Fi，上位机实时监控 | 远程调试和监控 |
| 升级主控 | 更换到STM32F4系列，支持更复杂算法 | 更强的计算能力 |
