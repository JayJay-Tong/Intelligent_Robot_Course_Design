## 1 系统概述

本课程设计的智能机器人系统由 **STM32F103C8T6 开发板（蓝牌核心板，俗称 Blue Pill）** 与 **STM32_10B 小车底板（功能扩展载板）** 两部分构成。Blue Pill 提供 ARM Cortex-M3 计算内核及最小系统电路；小车底板在 Blue Pill 的基础上扩展了电源管理、USB-串口下载、一键自动下载、各类传感器接口、舵机接口、无线通信接口、显示与发声器件，从而构成完整的机器人控制平台。在此平台上，外接 **L298N 双路 H 桥驱动模块** 驱动两路减速直流电机；感知系统由**车头前方的 HC-SR04 超声波测距模块**（前向墙壁/障碍距离）、**车头左右两侧的红外避障传感器**（左/右墙壁检测）、**车体中心的 CJ-M49 三轴加速度计**（转弯角度反馈）三类传感器构成，可对前、左、右三个方向的墙壁状态与车体转动姿态进行实时同步感知，配合右手法则完成迷宫自主导航任务。

**选定题目：** 智能机器人走迷宫（可拓展为迷宫灭火）。

**核心思想：** 以 Blue Pill 为计算核心，以小车底板为外设载体，以"前向超声 + 左右红外 + 三轴加速度计"复合感知系统为感知手段，以差速驱动为运动方式，以基于三路墙壁状态的右手法则决策配合加速度计闭环角度反馈为决策依据，构成"感知—决策—执行—反馈"闭环。

### 2.2 STM32F103C8T6 开发板（核心控制单元）

依据 `STM32F103C8T6开发板原理图.pdf`，Blue Pill 包含以下九个功能区：

- **MCU 核心**：U2: STM32F103C8T6（LQFP48），72 MHz Cortex-M3，64 KB Flash，20 KB SRAM；
- **电源（5V→3.3V）**：U1: RT9193-33 LDO 与 C5/C6/C7/C8/C15 滤波电容，将 5 V 输入稳压为 MCU 所需的 3.3 V；
- **时钟**：Y2（8 MHz HSE 晶振）为主时钟源，X1（32.768 kHz LSE 晶振）为 RTC 时钟源；
- **下载与调试**：P2: SWD 接口（VCC3V3 / SWDIO / SWDCLK / GND），支持 ST-Link / J-Link 烧录与在线调试；
- **引脚扩展**：P3、P4 两组 2×20-pin 排针，将 MCU 全部可用 IO 引出至板边；
- **启动模式**：P1 BOOT0/BOOT1 跳线配合 R3/R4（100 kΩ 下拉），可选 Flash / SystemMemory / SRAM 三种启动方式；
- **USB**：U3（USB-MICRO）经 R9/R11（20 Ω 限流）连接至 PA11/PA12，可选 USB-DFU 启动，但与红外传感器复用冲突；
- **板载指示**：D1（电源 LED）与 D2（PC13 用户 LED），分别指示上电状态与程序运行状态；
- **复位**：RESET 按键配合 R2（10 kΩ）与 C2（1 µF）构成上电及手动复位电路。

**重要提示（PA11/PA12 复用冲突）：** Blue Pill 上 USB 数据线 D-/D+ 已默认接到 PA11/PA12。本项目 PA11/PA12 被用作红外避障传感器输入，**因此使用本系统时不可同时使用 Blue Pill 自带 USB 与红外传感器**，下载与调试必须通过小车底板上的 **CH340C UART** 或 **SWD** 接口完成。

### 2.3 STM32_10B 小车底板（功能扩展载板）

依据 `STM32_10B 小车底板原理图.pdf`，载板共包含九大子电路，是机器人外设的统一物理载体：

#### 2.3.1 电源管理电路

电源管理电路主要由以下器件构成：BT1 为锂电池接口，提供 VCCBAT（典型 7.4 V）；输入端配有 C6（1000 µF）与 C4（100 nF）进行滤波；U1（A1117-3.3）为 LDO 稳压器，将 VCCBAT 降压至 3.3 V；输出端经 C1/C2（100 nF）与 C3（10 µF）滤波稳定；R6（4.7 kΩ）串联 LED1 构成电源指示灯。

> 提供两路电压：**VCCBAT** 直供 L298N / 电机 / 舵机；**3.3 V** 供 MCU、红外、超声波及 CJ-M49 加速度计。

#### 2.3.2 USB-串口通信电路（CH340C）

通信电路以 U2（CH340C）为核心，实现 USB 与 TTL 串口之间的双向转换。CN1（USB-B）为与 PC 连接的 USB 接口，C5（103）对数据线进行滤波。CH340C 的 TXD 连接 PA10（USART1 RX），RXD 连接 PA9（USART1 TX），由此实现 ISP 下载与串口调试输出。

> 该电路使得 PC 通过普通 USB 数据线即可对 MCU 进行串口下载与调试输出。

#### 2.3.3 一键自动下载电路

自动下载电路由三个器件协同完成控制时序：Q1（SS8050 NPN 三极管）配合 R1/R2 受 CH340C 的 DTR# 信号驱动，控制 MCU 的 NRST 引脚；Q2（SS8550 PNP 三极管）配合 R3/R4/R5 受 RTS# 信号驱动，控制 BOOT0 引脚；D1（1N4148）作为时序隔离二极管防止信号倒灌。

**自动下载时序：** PC 上位机（如 FlyMcu / STM32CubeProgrammer）通过 DTR# / RTS# 的组合电平自动拉低 NRST 并拉高 BOOT0，使 MCU 进入 SystemMemory ISP 启动模式，自动完成擦写后再复位运行。**省去用户手动按住 BOOT0 + 按 RESET 的步骤。**

#### 2.3.4 外设接口汇总

各外设接口分配如下：

- **S1（用户按键）** → PA15，上拉输入，按下为低电平，用于启动或切换模式；
- **J3（左红外避障）** → PA11，三针（VCC/GND/DO），检测左侧墙壁；
- **J6（右红外避障）** → PA12，三针，检测右侧墙壁；
- **J5（电机驱动板供电）** → VCCBAT，仅供电，将电池电压引出给 L298N；
- **J4（舵机接口）** → PB5（TIM3_CH2），三针（信号/VCC/GND）；
- **P1（循迹模块接口）** → PB12 / PB13，四针（VCC/GND/S1/S2）；
- **P3（超声波模块接口）** → PB14（TRIG）/ PB15（ECHO），四针，本项目接 HC-SR04；
- **P2（三轴加速度计/无线通信接口）** → PB10（I²C2_SCL）/ PB11（I²C2_SDA），四针，本项目接 CJ-M49；
- **红外接收头** → PA8，三针，配合定时器输入捕获解码 NEC 协议；
- **BUZ1（蜂鸣器）** → PB0，经 V1（SS8050）驱动，高电平鸣响；
- **SM1（共阳数码管）** → PA0~PA7（段码 a~g + dp），共阳极接 3.3 V，限流电阻 R7；
- **H1 / H2（1×20 排针扩展头）** → 直接引出 MCU 全部可用 GPIO；
- **S2（8 位拨码开关）** → 功能配置 jumper。

> **关于 P2 接口复用：** 载板原理图上 P2 标注为"WIFI 接口/蓝牙接口"，其底层 MCU 引脚 PB10 / PB11 同时具备 **USART3** 与 **I²C2** 两种复用功能。本项目不使用无线通信，将 P2 配置为 **I²C2 主机模式**，用于读取 CJ-M49 三轴加速度计。
>
> **关于 P3 接口：** P3 在原理图上即标注为"超声波模块接口"，引脚 PB14 / PB15 直接用作 HC-SR04 的 TRIG / ECHO，本项目按原始设计使用。

#### 2.3.5 本课题实际使用的接口

本课题实际使用的接口分配：左红外避障经 J3 连接 PA11，检测左侧墙壁；右红外避障经 J6 连接 PA12，检测右侧墙壁；前向超声波（HC-SR04）经 P3 连接 PB14（TRIG）和 PB15（ECHO），检测前方障碍距离；三轴加速度计（CJ-M49）经 P2 连接 PB10（SCL）和 PB11（SDA），通过 I²C2 读取转弯角速度信息；启动按键经 S1 连接 PA15，一键启动迷宫导航；左电机正/反转 PWM 由 PB6 和 PB7 输出，右电机正/反转 PWM 由 PB8 和 PB9 输出，均经 H2 排针外接 L298N；电机驱动板由 J5（VCCBAT）电池直供；调试串口（下载 + printf）使用 PA9 / PA10，经 CH340C 连接至 USB；蜂鸣器（BUZ1，PB0）可选用于灭火点报警指示。

### 2.4 执行机构（L298N + 双减速电机）

L298N 驱动模块采用双路 H 桥芯片，控制端 IN1/IN2 驱动左电机，IN3/IN4 驱动右电机，ENA/ENB 为使能端。逻辑电平兼容 5 V TTL 及 3.3 V，驱动电压范围 5 V~46 V，单路额定电流 2 A（典型值）。

**STM32 → L298N 接线（经 H2 引出）：** PB6（TIM4_CH1）接 IN1 控制左电机正转，PB7（TIM4_CH2）接 IN2 控制左电机反转，PB8（TIM4_CH3）接 IN3 控制右电机正转，PB9（TIM4_CH4）接 IN4 控制右电机反转。

**电机方向逻辑（以左电机为例）：** IN1 输出 PWM、IN2 输出 0 时电机正转（前进）；IN1 输出 0、IN2 输出 PWM 时电机反转（后退）；两端均为 0 时自由滑行；两端均为高电平时短路制动。

**PWM 参数：** TIM4 预分频 (PSC) = 36-1，自动重装 (ARR) = 100-1 → PWM 频率 = 72 MHz ÷ 36 ÷ 100 = **20 kHz**（人耳听不到，电机平稳）。占空比 0~99 对应 0%~100% 转速。

### 2.5 传感器原理

#### 2.5.1 左/右红外避障传感器（侧墙感知）

红外避障传感器由红外发射管（LED1）和接收管（光敏二极管）构成：

```text
         红外光
LED1 ─────────────────▶  墙壁  ─────────▶  接收管 ──▶ 比较器 ──▶ DO
                          (反射)                       (阈值)
```

- 当传感器前方 5~10 cm 处存在反射面（墙壁）时，红外光被反射，接收管导通，比较器输出 **低电平 (DO=0)** 表示"有墙"；
- 当前方无障碍物，红外光未被反射，比较器输出 **高电平 (DO=1)** 表示"无墙"；
- 检测距离可通过模块上蓝色电位器调节（约 2~30 cm）。

#### 2.5.2 HC-SR04 超声波测距传感器（前向墙壁感知）

HC-SR04 是基于 40 kHz 超声波收发的测距模块，由 STM32 给出 10 µs 触发脉冲后，模块发射 8 个 40 kHz 声波脉冲并通过 ECHO 引脚返回与脉冲宽度成正比的回波信号。

```text
                ┌────────────────────────────────┐
   STM32 PB14   │  10 µs ▔▔▔▔                    │  TRIG
   ──────────▶ │                                 │
                │  40 kHz × 8 ──▶ 墙壁 ◀── 回波  │
                │                                 │
   STM32 PB15   │             ▔▔▔▔▔▔▔▔▔          │  ECHO
   ◀────────── │             |←─ T_echo ─→|     │
                └────────────────────────────────┘

   距离 d = (T_echo × c_sound) / 2  (其中 c_sound ≈ 340 m/s)
         = T_echo[µs] × 0.17 mm/µs
```

HC-SR04 的主要规格：检测范围为 2~400 cm，本项目工作区为 2~30 cm；测距精度 ±3 mm；工作电压 5 V（载板 P3 输出，模块自带 LDO 降压）；工作频率 40 kHz；触发方式为 TRIG 端输入不低于 10 µs 的高电平脉冲；回波信号 ECHO 输出脉冲宽度（µs）约等于距离乘以 58；MCU 接入方式为 TRIG 连接 PB14（GPIO 推挽输出），ECHO 连接 PB15（GPIO 输入 + TIM2 计时）；推荐采样周期 25~50 ms，两次触发间隔不低于 60 ms 以防回波串扰。

**实现方式：** 采用 GPIO 触发 + TIM2 微秒级计时的轮询法测距。TIM2 配置 PSC = 72-1，CNT 自增分辨率 1 µs。MCU 拉高 PB14 持续 10 µs 后清零，随后等待 PB15 拉高，记录起始计数值 t₁；待 PB15 落下，记录 t₂，距离 d_mm = (t₂-t₁) × 0.17。

**前方"有墙"判定阈值：** d_front ≤ **15 cm** 视为"前方有墙"，d_front > 15 cm 视为"前方畅通"。

#### 2.5.3 CJ-M49 三轴加速度计（转弯角度感知）

CJ-M49 是基于 MEMS 工艺的三轴数字加速度计模块，采用 I²C 总线与主控通信。其主要规格：检测 X（前后）、Y（左右）、Z（垂直）三轴加速度；量程可通过软件选择 ±2 g / ±4 g / ±8 g / ±16 g；输出为 16-bit 数字信号；工作电压 3.3 V；本项目使用 I²C2，SCL 接 PB10，SDA 接 PB11；采样率典型值 100 Hz；模块安装在小车底盘几何中心，水平正置。

**工作原理：**

```text
   小车原地左旋示意（俯视）：
                              ω (yaw rate)
        ┌────────────┐         ↻
        │  CJ-M49    │
        │   ◯  Y轴   │  ← 旋转时 Y 轴感受到切向 / 离心加速度分量
        │  ┼  X轴    │  ← 同时 X 轴感受到正交分量
        └────────────┘
   差速旋转时（左轮反转 / 右轮正转），传感器随车体一起做圆周运动。
```

**用于转弯角度判断的算法：**

设采样周期 ΔT（约 10 ms），传感器输出三轴加速度 $a_x$, $a_y$, $a_z$。

1. **静态校准**：上电后小车静止采集 200 ms 数据，求得各轴零偏 $a_{x0}$, $a_{y0}$, $a_{z0}$；
2. **运动加速度提取**：去除重力分量与零偏，得到运动加速度分量 $a'_x = a_x - a_{x0}$, $a'_y = a_y - a_{y0}$；
3. **横向加速度合成**：原地旋转时离心加速度模 $|a_{lat}| = \sqrt{a'_x{}^2 + a'_y{}^2}$；
4. **角速度估算**：在已知差速旋转的等效旋转半径 $r$ 下 $\omega = \sqrt{|a_{lat}| / r}$（标定一次即可固化）；
5. **角度积分**：$\Delta\theta = \int_0^t \omega(t)\,\mathrm{d}t \approx \sum \omega_i \cdot \Delta T$；
6. **判停条件**：$|\Delta\theta| \geq 90°$（或 180°）即停止转弯。

相较于"固定时间法"，加速度计闭环法对电池电压下降、地面摩擦差异、左右轮速度不匹配均具有较强的鲁棒性。

## 3 系统工作原理分析

### 3.1 上电启动流程

```text
        上电（开电源开关）
              │
              ▼
   ┌──────────────────────────────┐
   │ 电源管理子电路启动           │
   │ VCCBAT → A1117 → 3.3V        │
   │ → MCU 上电复位 (POR)         │
   └──────────────┬───────────────┘
                  ▼
   ┌──────────────────────────────┐
   │ 启动 Bootloader（依 BOOT0）   │
   │  BOOT0=0 → 从 Flash 启动     │
   └──────────────┬───────────────┘
                  ▼
   ┌──────────────────────────────────┐
   │ main() 执行外设初始化             │
   │  RCC / SysTick / GPIO             │
   │  TIM4 → PWM 输出                  │
   │  PA11 / PA12 → 上拉输入           │
   │  PA15 → 上拉输入（按键）          │
   │  PA9/PA10 → USART1 调试           │
   │  PB14/PB15 → 超声波 GPIO + TIM2   │
   │  PB10/PB11 → I2C2，初始化 CJ-M49  │
   │  执行 200 ms 加速度计零偏校准     │
   └──────────────┬───────────────────┘
                  ▼
   ┌──────────────────────────────┐
   │ 等待按键按下                  │
   │  Key_GetNum() != 0 ?          │
   └──────────────┬───────────────┘
                  ▼
   ┌──────────────────────────────┐
   │ 进入主控制循环                │
   │  while(1) { 感知→决策→执行 } │
   └──────────────────────────────┘
```

### 3.2 迷宫导航核心算法（三传感器右手法则 + 角度闭环）

**算法思想：** 迷宫中任一连通区域，机器人保持"右手始终贴墙"前行，必能遍历该连通区域上的所有通道，并最终离开迷宫。本项目以**前向超声波 + 左右红外**三路传感器同时识别路口形态，以**三轴加速度计**反馈完成精确 90°/180° 转弯。

**三传感器八状态决策规则：**

设 F 表示前向超声波测距（d ≤ 15 cm 为"近"，即前方有墙），L 表示左红外（0 = 有墙），R 表示右红外（0 = 有墙）。八种状态的决策规则如下：

- **F远、L有墙、R有墙**：正常走廊，两侧均有墙，执行直行；
- **F远、L无墙、R有墙**：左侧出现路口，执行左转 90°（加速度计闭环）；
- **F远、L有墙、R无墙**：右侧出现路口，执行右转 90°（闭环）；
- **F远、L无墙、R无墙**：十字路口且前方仍畅通，按右手优先执行右转 90°；
- **F近、L有墙、R有墙**：**死端口（三面均有墙）**，执行掉头 180°（闭环）；
- **F近、L无墙、R有墙**：T 形路口，前方堵、左方通，执行左转 90°；
- **F近、L有墙、R无墙**：T 形路口，前方堵、右方通，执行右转 90°；
- **F近、L无墙、R无墙**：T 形路口，前方堵、左右均通，按右手优先执行右转 90°。

> 加入前向超声波后，决策表由 4 状态扩展为 8 状态，机器人可精确识别**死端口**并自动 180° 掉头，无需依赖侧墙误判后强行倒退。

**转弯后传感器读数问题说明：**

机器人完成 90° 转弯后，车体仍处于路口几何中心位置，左右红外传感器此时"看"到的是路口豁口而非新走廊侧墙，会产生 `L=无墙、R=无墙` 的误读。若立即进入下一轮状态机决策，将触发错误的连续转弯。**解决方法：每次转弯结束后，先盲走约 150 mm 进入新走廊，再开始读传感器决策。**

**90°/180° 转弯 + 盲走进廊子流程：**

```text
   ┌──────────────────────────────────┐
   │ 触发 TurnLeft90 / Right90 / U180 │
   └────────────┬─────────────────────┘
                ▼
   ┌────────────────────────────┐
   │ 角度累计变量 θ = 0          │
   │ 启动差速旋转 PWM            │
   │ 设定目标角 θ_target          │
   │  (90°/180°)                 │
   └────────────┬───────────────┘
                ▼
   ┌────────────────────────────┐
   │ 每 ΔT=10 ms 读取 CJ-M49     │
   │ 计算瞬时 ω → θ += ω·ΔT     │
   └────────────┬───────────────┘
                ▼
   ┌────────────────────────────┐
   │   |θ| ≥ θ_target - δ ?      │
   └────┬──────────────────┬────┘
        │No                │Yes
        ▼                  ▼
   ┌─────────┐    ┌─────────────────────────────────────┐
   │ 继续转弯 │    │ 停止 PWM，结束转弯                   │
   └─────────┘    └──────────────┬──────────────────────┘
                                 ▼
                  ┌──────────────────────────────────┐
                  │ 盲走进廊：Robot_ForwardBlind(150) │
                  │ 以 FORWARD_SPEED 直行 150 mm      │
                  │ 期间不读传感器、不做决策           │
                  └──────────────┬───────────────────┘
                                 ▼
                  ┌──────────────────────────────────┐
                  │ 返回主状态机，重新读三路传感器     │
                  └──────────────────────────────────┘
```

> **盲走距离参数 `FORWARD_BLIND_MM`（建议 150 mm）：** 应略大于走廊宽度的一半，使车体完全驶入新走廊后侧墙才进入红外检测范围。实际调试时可在 100~200 mm 范围内微调，过短则传感器仍读到路口豁口，过长则可能错过下一路口。

### 3.3 差速运动学

两轮差速底盘以左右轮速度差实现转向，各运动模式如下：前进时左右轮同向同速（均输出 +V）；后退时均反向（均输出 −V）；左转时左轮停或反转（0 或 −V）、右轮正转（+V）；右转时右轮停或反转（0 或 −V）、左轮正转（+V）；原地左旋时左轮 −V、右轮 +V，用于 90°/180° 角度闭环转弯；原地右旋时左轮 +V、右轮 −V，同样用于闭环转弯；制动时双轮均置 0，自由滑行。

### 3.4 控制闭环

```text
   ┌─────────────────┐  ┌──────────────────┐  ┌──────────────────┐
   │ 左/右红外避障    │  │ HC-SR04 超声波    │  │ CJ-M49 三轴加速度 │
   │ PA11/PA12 (DO)   │  │ PB14/PB15        │  │ I²C2: PB10/PB11  │  ← 感知层
   └─────────┬───────┘  └─────────┬────────┘  └─────────┬────────┘
             │ GPIO读取            │ 计时回波              │ I²C读取
             ▼                     ▼                       ▼
   ┌─────────────────────────────────────────────────────────────┐
   │              融合决策模块                                    │
   │  右手法则八状态机（路口/死端口识别） + 角度积分（转弯监控）   │  ← 决策层
   └──────────────────────────┬──────────────────────────────────┘
                              │ 控制指令
                              ▼
   ┌──────────────────────────┐
   │  PWM 占空比计算           │
   │  TIM4_CH1~CH4 输出        │  ← 执行层
   │  PB6 / PB7 / PB8 / PB9    │
   └──────────────┬───────────┘
                  │ 5V H桥
                  ▼
   ┌──────────────────────────┐
   │  L298N → 双电机           │
   │  小车前进/转弯/掉头/停止  │
   └──────────────┬───────────┘
                  │ 物理位姿变化
                  └────► 反馈（三传感器同时感知）─┐
                                                    │
                  ◄─────────────────────────────────┘
```

红外避障构成"**侧墙位置反馈**"，超声波构成"**前向距离反馈**"，三轴加速度计构成"**朝向角度反馈**"，三路反馈共同闭环。

## 4 完成迷宫导航任务的设计开发步骤

下面给出从立项到验收的全流程八阶段开发步骤，每阶段附**验证目标（Done Criteria）**：

### 步骤 1：需求分析与方案确定

- 明确任务目标：在 1.5 m × 1.5 m 的标准迷宫中自主行驶，从入口到达出口；
- 选定方案：以小车底板 + Blue Pill + L298N + 双红外 + 超声波 + CJ-M49 为硬件平台，软件采用基于三传感器的右手法则八状态决策 + 加速度计闭环转弯；
- 确认验收标准：5 次尝试中至少 4 次成功通过，单次时间 < 3 min，转弯精度 ±5°，死端口可识别并自动掉头。
- **Done：** 形成《总体方案设计》文档并通过开题评审。

### 步骤 2：硬件搭建与连接

1. 将 Blue Pill 插入小车底板 SK1 插座；
2. 用三针线将左/右红外传感器接入 J3 / J6（注意 VCC 接 3.3 V）；
3. 用四针线将 HC-SR04 接入 P3 接口（VCC=5V / TRIG=PB14 / ECHO=PB15 / GND），安装在车头正前方并保持声波路径不被结构件遮挡；
4. 用四针线将 CJ-M49 接入 P2 接口（VCC=3.3V / SCL=PB10 / SDA=PB11 / GND）；
5. 用四针线将 L298N IN1~IN4 接至 H2 的 PB6 / PB7 / PB8 / PB9；
6. 将 L298N 电源端 (+12 V / GND) 接至 J5（VCCBAT）；
7. L298N OUT1/2 接左电机，OUT3/4 接右电机；
8. 整机共地（STM32 GND = L298N GND = CJ-M49 GND = HC-SR04 GND = 电池负极）；
9. 万用表通断检查，确认无短路；CJ-M49 安装在小车底盘几何中心位置并保持水平正置，HC-SR04 探头中心轴线与车体前进方向一致。

- **Done：** 通电后 LED1 亮，PC13 LED 闪烁，HC-SR04 与 CJ-M49 上电指示灯亮，整机电流 < 250 mA。

### 步骤 3：开发环境搭建

1. 安装 Keil MDK-ARM v5（含 STM32F1 Pack）或 STM32CubeIDE；
2. 安装 ST-Link / CH340C 驱动；
3. 配置工程：选择目标芯片 STM32F103C8T6，配置时钟 72 MHz，加入 SPL 或 HAL 库，使能 I²C2、TIM2（1µs 计时基准）、TIM4（PWM）；
4. 写最小工程（PC13 LED 闪烁）验证 toolchain。

- **Done：** 编译 0 错误，下载后 PC13 LED 以 1 Hz 闪烁。

### 步骤 4：基础驱动开发

各驱动子模块按以下方式开发与验证：`PWM.c` 提供 `PWM_Init()` 与 `PWM_SetCompareN()`，通过示波器观察 PB6~PB9 的输出方波进行验证；`Motor.c` / `robot.c` 提供 `Robot_Forward(speed)`、`Robot_TurnLeft90()` 与 `Robot_Stop()`，对单轮独立上电测试，左右轮分别验证；`Irobstacle.c` 提供 `IR_GetLeft()` 与 `IR_GetRight()`，手遮传感器并观察串口打印电平；`Ultrasonic.c` 提供 `US_Init()` 与 `US_GetDistanceMM()`，用直尺移动遮挡物并比对读数；`IMU.c` 提供 `IMU_Init()`、`IMU_ReadAccel(&ax,&ay,&az)` 与 `IMU_GetYawDelta()`，旋转小车 90° 后通过串口打印累计 θ 值验证；`Key.c` 提供 `Key_GetNum()`，按下 S1 时确认返回非零值；`OLED.c`（可选）提供 `OLED_ShowStr()`，用于实时显示传感器状态。各子模块独立测试通过后，要求超声波在 5~200 mm 区间误差 ≤ ±5 mm，IMU 旋转 90° 累计误差 ≤ ±3°，串口能稳定打印三路传感器数据。

### 步骤 5：迷宫导航算法集成

1. 在 `main.c` 中编写**三传感器八状态**右手法则状态机；
2. 实现 `Robot_TurnLeft90()` / `Robot_TurnRight90()` / `Robot_UTurn180()` 三个闭环转弯接口，内部循环读取 `IMU_GetYawDelta()` 直至达到目标角才返回；
3. 调整关键参数：
   - 前进速度 `FORWARD_SPEED`（建议 60~80）
   - 转弯速度 `TURN_SPEED`（建议 60~70，决定 ω 大小）
   - 前墙阈值 `FRONT_WALL_MM`（建议 150 mm）
   - 目标转角 `TURN_TARGET_DEG`（90° / 180°）
   - 角度阈值留量 `TURN_GUARD_DEG`（建议 5°，补偿惯性过冲）
   - 加速度计采样周期 `IMU_SAMPLE_MS`（10 ms）
   - 超声波采样周期 `US_SAMPLE_MS`（50 ms）
   - 旋转半径标定值 `TURN_RADIUS`（用直角弯实测反推）；
   - 转弯后盲走距离 `FORWARD_BLIND_MM`（建议 150 mm，防止在路口豁口处误读传感器）；
4. 在直线 + 单 90° 弯 + 死端口的简易迷宫中跑通直行 / 转弯 / 掉头。

- **Done：** 单弯迷宫一次通过，转弯角度误差 ≤ ±5°，死端口能正确识别并 180° 掉头。

### 步骤 6：完整迷宫调试与调参

用纸板搭建包含左转、右转、T 形、十字及死端口的完整迷宫，反复进行测试。针对不同失败工况逐一调整：若小车偏向一侧，则降低偏弯一侧的速度或加入修正延时；若前墙出现漏检或虚检，则调整 `FRONT_WALL_MM` 阈值或加入 3 次确认机制；若转弯不足或过冲，则调整 `TURN_GUARD_DEG`；若发生撞墙，则降低 `FORWARD_SPEED` 或提高红外灵敏度。每次测试均需记录测试日志，包括成功与失败的位置、耗时、每次转弯的实际累计 θ 以及每次前墙判定距离，以便逐步收敛参数。验收标准：成功率 ≥ 80%，平均通过时间 ≤ 3 min，平均转弯角度误差 ≤ ±5°。

### 步骤 7：扩展功能（灭火）集成（可选）

1. 将火焰传感器 DO 接入空闲 GPIO（如 PA8 或循迹接口 P1 的备用引脚）；
2. 在主循环中检测火焰电平；
3. 检测到火焰 → 停车 + 蜂鸣器 (BUZ1, PB0) 鸣叫 + LED 报警。

- **Done：** 在灭火点停车并发出报警，3 s 内响应。

### 步骤 8：验收与文档撰写

1. 准备验收演示（含至少 2 次完整跑迷宫，含至少 1 次死端口掉头）；
2. 整理代码与报告（含硬件接线表、软件流程图、超声波/IMU 标定记录、调参记录、测试视频）；
3. 提交课程设计报告与答辩 PPT。

- **Done：** 通过现场演示与答辩。

## 5 关键技术指标

各关键技术指标及测量方法：迷宫通过成功率目标 ≥ 80%，通过 5 次尝试统计；单次通过时间目标 < 3 min，以按键按下至到达出口的秒表计时；红外检测距离 5~10 cm，用直尺测量并调节电位器；**超声波测距工作范围 2~30 cm**，通过直尺标定；**超声波测距精度目标 ≤ ±5 mm**，在 5/10/15/20/25/30 cm 五点比对验证；**前墙判定阈值设为 15 cm**，在代码中配置；最大前进速度约 0.3 m/s，以滚距除以时间计算；转弯角度误差目标 ≤ ±5°，用角度尺测量并由 CJ-M49 闭环保证；加速度计静止角度漂移 ≤ ±3°/10 s，在静止状态下读取累计 θ 验证；死端口识别成功率 100%，测试方法为在死端口前停车并确认 180° 掉头成功；工作电压 7.4 V（锂电池），用万用表测量；持续工作时间目标 ≥ 30 min，满电连续运行验证。

## 6 系统局限性与改进方向

### 6.1 当前局限

1. **PA11 / PA12 USB 复用冲突。** Blue Pill 板载 USB D-/D+ 与红外传感器输入复用，本系统下载必须走 CH340C 或 SWD，无法启用原生 USB。
2. **加速度计零偏温漂。** CJ-M49 的零偏随温度有缓慢漂移，长时间运行后转弯精度可能下降。每次上电执行 200 ms 静态校准可缓解此问题。
3. **超声波串扰风险。** 多次连续触发若间隔 < 60 ms，前一次的回波可能干扰下一次测距，本项目通过设置 50 ms 采样周期 + 中值滤波规避。
4. **超声波在斜墙下读数偏大。** 当墙壁与超声波探头不正对时，反射声波被斜射出去，导致漏检；右手法则正常通行时探头基本正对墙壁，但 T 形偏角处需软件容错。
5. **无地图记忆。** 右手法则无法处理孤岛型迷宫，且无法走最短路径。

### 6.2 改进方向

改进方向与预期效果：

- **升级到 6 轴 IMU**：用 MPU6050 / ICM-20602 替代 CJ-M49，引入陀螺仪直接积分 yaw，可将转弯精度提升至 ±2° 且无需旋转半径标定；
- **增加多路超声波**：在车头左右各加一路超声波，提高斜墙工况下的鲁棒性；
- **增加路径记忆**：用 SRAM 维护节点表并引入 Flood Fill 算法，使机器人在第二次跑迷宫时即可走最短路径；
- **远程监控**：将 P2 改接 ESP8266（与 CJ-M49 通过拨码开关二选一），实现手机端实时状态监控；
- **视觉拓展**：接入外置 OpenMV / K210 摄像头模块，为后续目标识别提供视觉能力。
