# 第一部分　总体方案设计

## 1.1 题目名称及简介

**题目名称：** 基于 STM32F103C8T6 的迷宫智能机器人设计

**项目简介：**

本项目针对**智能机器人走迷宫**这一参考题目，设计并实现一款能够在未知 / 半结构化迷宫环境中自主导航的智能小车。机器人以 **STM32F103C8T6**（Blue Pill 核心板）为主控、以 **STM32_10B 小车底板**为外设载体、以 **L298N 双路 H 桥**驱动两路减速直流电机。感知系统由三类互补传感器构成：**车头前方的 HC-SR04 超声波测距模块**负责前向墙壁/障碍距离测量、**车头左右两侧的红外避障传感器**负责侧墙探测与路口识别、**底盘中心的 CJ-M49 三轴加速度计**负责小车转弯角度的闭环测量。决策算法采用**右手法则**（Right-Hand Rule）的三传感器八状态扩展形式选择行进方向，由加速度计积分反馈控制每次 90° / 180° 转弯的精度，最终在指定时间内由迷宫入口行驶至出口。

本项目融合了**嵌入式 C 程序设计、I²C 总线通信、超声波测距与脉宽计时、传感器接口与标定技术、PWM 调速、机电执行机构、控制流程设计、惯性测量与角度积分**等多门课程的知识，具有较强的工程综合性，可在完成基础迷宫导航的基础上拓展为**迷宫灭火**等扩展任务。

## 1.2 智能机器人系统功能及指标设计

### 1.2.1 应用场景设定

- **物理场景：** 1.5 m × 1.5 m 标准白底纸板迷宫，墙高约 10 cm（保证红外/超声波均被反射），通道宽度 18~25 cm；
- **任务场景：** 机器人从迷宫指定入口出发，自主行驶通过若干 90° 直角弯（含左弯、右弯、T 形、十字、死端口），到达指定出口；
- **扩展场景：** 在出口位置放置蜡烛 / 火焰，机器人到达后自动停车并报警（灭火模式）。

### 1.2.2 系统功能设计

### 1.3.2 机械结构

- **底盘：** 双层亚克力 / 铝合金底盘，长 18 cm × 宽 14 cm；
- **驱动轮：** 直径 65 mm × 2，由 TT 减速直流电机驱动；
- **万向轮：** 直径 25 mm × 1，置于车尾形成三点支撑；
- **红外传感器支架：** 车头前端两侧 L 型支架，使红外传感器距地面 4~6 cm（对齐迷宫墙壁）；
- **HC-SR04 安装位置：** 车头正前方中心，两个探头中轴线与车体前进方向严格一致，距地面 4~6 cm，避免被前轮或车体结构件遮挡；
- **CJ-M49 安装位置：** 小车底盘几何中心位置，通过亚克力垫板与底盘刚性连接，保证传感器水平正置（XY 平面与地面平行），避免悬挂以减小车体震动对加速度读数的耦合；
- **电池仓：** 底盘中部，容纳 2×18650 锂电池。

### 2.1.2 主用传感器规格

#### 红外避障传感器（×2，侧墙感知）

| 参数项 | 规格 |
|--------|------|
| 类型 | 红外反射式（红外发射 + 接收 + LM393 比较器） |
| 工作电压 | DC 3.3 V ~ 5 V |
| 检测距离 | 2 ~ 30 cm（电位器可调） |
| 输出 | DO：数字 TTL；AO：模拟（本项目仅用 DO） |
| 信号逻辑 | 有障碍 → LOW（0）；无障碍 → HIGH（1） |
| 检测角度 | 约 35° |
| 响应时间 | < 1 ms |
| 接口针脚 | VCC / GND / DO |
| 接入位置 | 小车底板 J3（左）/ J6（右），分别对应 PA11 / PA12 |

**选型理由：**

1. 数字输出，主控直接 GPIO 读取，无需 ADC，资源占用最低；
2. 响应快（< 1 ms），满足实时避障；
3. 检测距离可调，适配迷宫墙间距；
4. 与小车底板 J3 / J6 接口完全匹配（PA11/PA12 上拉输入）。

#### HC-SR04 超声波测距传感器（×1，前向感知）

| 参数项 | 规格 |
|--------|------|
| 类型 | 40 kHz 超声波收发测距模块 |
| 检测距离 | 2 cm ~ 400 cm（本项目工作区 2 ~ 30 cm） |
| 测距精度 | ±3 mm |
| 工作电压 | 5 V（载板 P3 接口的 VCC 引脚） |
| 工作电流 | 静态 < 2 mA，工作 < 15 mA |
| 触发脉冲 | TRIG 输入 ≥ 10 µs 高电平 |
| 回波信号 | ECHO 脉宽 (µs) = 距离 (cm) × 58 |
| 采样周期 | ≥ 60 ms（防回波串扰） |
| 接入位置 | 小车底板 **P3 接口**（VCC/TRIG/ECHO/GND） |
| MCU 引脚 | **PB14 (TRIG，GPIO 推挽输出) / PB15 (ECHO，GPIO 输入)** |
| 测时器件 | **TIM2**（PSC=71, ARR=0xFFFF，1 µs 分辨率） |

**选型理由：**

1. 距离信息为模拟物理量（cm），相较于红外的"0/1"二值输出，可基于距离阈值实现多级判断（畅通/接近/紧贴/死端口）；
2. 工作距离 2~400 cm，覆盖迷宫所有可能的前墙距离；
3. 与 P3 接口针脚定义完全一致，无需改板；
4. 单一发射轴，可严格识别正前方墙壁，与左右红外形成"前-左-右"完整 120° 覆盖。

#### CJ-M49 三轴加速度计（×1，转弯角度感知）

| 参数项 | 规格 |
|--------|------|
| 类型 | MEMS 三轴数字加速度计模块 |
| 检测轴 | X（前后） / Y（左右） / Z（垂直） |
| 量程 | ±2 g / ±4 g / ±8 g / ±16 g（软件可配） |
| 输出位宽 | 16-bit ADC（每轴） |
| 接口 | I²C（7-bit 地址，400 kHz 标准模式） |
| 工作电压 | 3.3 V |
| 采样率 | 软件可配，本项目取 100 Hz |
| 接入位置 | 小车底板 **P2 接口**（VCC/SCL/SDA/GND） |
| MCU 引脚 | **PB10 (I²C2_SCL) / PB11 (I²C2_SDA)** |

**选型理由：**

1. 数字 I²C 接口，仅占用 2 根线，配置灵活；
2. 三轴同步采样，便于通过对横向加速度的积分估算转弯角速度与角度；
3. 量程可软件切换，满足小车转弯过程中的小加速度采样（±2 g 精度更高）；
4. 与 P2 接口针脚直接兼容（PB10/PB11 同时支持 USART3 与 I²C2，本项目复用为 I²C2）；
5. 配合 200 ms 静态零偏校准，可将单次 90°/180° 转弯角度误差控制在 ±5° 以内。

#### 火焰传感器（可选，扩展灭火功能）

| 参数项 | 规格 |
|--------|------|
| 检测波长 | 760 ~ 1100 nm（近红外） |
| 检测角度 | 60° 锥角 |
| 输出 | DO（数字）+ AO（模拟） |
| 接入位置 | 可借用循迹接口 P1（PB12 / PB13）的备用引脚 |

### 2.2.2 详细接线表

#### 表 A：红外传感器接线（共 6 根线）

| 传感器引脚 | 接至小车底板 | MCU 引脚 |
|------------|--------------|----------|
| 左 VCC | J3 [VCC] | 3.3 V |
| 左 GND | J3 [GND] | GND |
| 左 DO  | J3 [信号] | **PA11**（上拉输入） |
| 右 VCC | J6 [VCC] | 3.3 V |
| 右 GND | J6 [GND] | GND |
| 右 DO  | J6 [信号] | **PA12**（上拉输入） |

#### 表 B：HC-SR04 超声波接线（共 4 根线）

| 模块引脚 | 接至小车底板 P3 接口 | MCU 引脚 | 模式 |
|----------|----------------------|----------|------|
| VCC | P3 [VCC] | 5 V | — |
| GND | P3 [GND] | GND | — |
| TRIG | P3 [TRIG] | **PB14** | GPIO 推挽输出（默认低）|
| ECHO | P3 [ECHO] | **PB15** | GPIO 浮空输入（配合 TIM2 计时）|

> 备注：HC-SR04 工作电压为 5 V，载板 P3 接口 VCC 即接载板 5V 电源轨。ECHO 引脚输出为 5V 电平，但 STM32F103 的 PB15 在 5V 容忍（FT）范围内，可直接连接，无需电平转换。

#### 表 C：CJ-M49 三轴加速度计接线（共 4 根线）

| 模块引脚 | 接至小车底板 P2 接口 | MCU 引脚 | 模式 |
|----------|----------------------|----------|------|
| VCC | P2 [VCC] | 3.3 V | — |
| GND | P2 [GND] | GND | — |
| SCL | P2 [SCL/TX] | **PB10 (I²C2_SCL)** | AF_OD（复用开漏） |
| SDA | P2 [SDA/RX] | **PB11 (I²C2_SDA)** | AF_OD（复用开漏） |

> 注：P2 接口物理上的 4 针为 VCC / TX / RX / GND，对应 STM32 引脚 PB10 / PB11。本项目通过软件配置将 PB10/PB11 复用为 I²C2，与 CJ-M49 模块上的 SCL/SDA 一一对应。若模块本身未集成 I²C 上拉电阻，需在 SCL/SDA 与 3.3 V 之间各加 4.7 kΩ 上拉电阻。

#### 表 D：电机驱动接线

| L298N 引脚 | 接至 | MCU 引脚 / 电源 | 模式 |
|------------|------|------------------|------|

| GND | 整机共地 | — | — |
| OUT1 / OUT2 | 左电机两极 | — | — |
| OUT3 / OUT4 | 右电机两极 | — | — |

### 2.2.3 引脚冲突与复用说明

| 项目 | 说明 | 处理方案 |
|------|------|----------|
| Blue Pill USB D-/D+ 占用 PA11/PA12 | 与红外传感器输入冲突 | 不启用 Blue Pill 原生 USB，下载走 CH340C 或 SWD |
| P2 接口默认为 WiFi/BT (USART3) | 本项目用作 I²C2 连接 CJ-M49 | 软件配置 PB10/PB11 为 I²C2 复用，无需硬件改动 |

| BOOT0 / BOOT1 | 一键自动下载电路自动控制 | 用户无需手动设置跳线 |

### 2.3.3 库选择

**采用 HAL + LL 混合库**（CubeMX 默认输出），原因：

1. HAL 抽象层好，跨芯片移植方便，I²C 驱动开箱即用；
2. PWM / GPIO / 超声波微秒级计时等高频操作通过 LL 实现以保证效率；
3. 现有工程脚手架（`script/` 目录）已基于 HAL 库构建。

如对资源占用敏感，可改用 SPL（标准外设库）。

### 2.4.5 IMU 模块详细子流程

```
   Robot_TurnLeft90():
   ┌──────────────────────────────────┐
   │ θ ← 0;  t0 ← HAL_GetTick()       │
   │ PWM: 左 -V, 右 +V (原地左旋)     │
   └───────────────┬──────────────────┘
                   ▼
   ┌──────────────────────────────────┐
   │ 每 10 ms 一拍：                  │
   │  IMU_ReadAccel(&ax,&ay,&az)      │
   │  去零偏 → a'_lat = √(ax²+ay²)    │
   │  ω = √(a'_lat / r_turn)          │
   │  θ += ω · 0.01                   │
   └───────────────┬──────────────────┘
                   ▼
            ┌─────────────┐
            │ θ ≥ 90°-δ? │──No──▶ 继续循环
            └──────┬──────┘
                   │Yes
                   ▼
   ┌──────────────────────────────────┐
   │ PWM 全部归 0，刹车                │
   │ 短暂等待 50 ms 让车体停稳          │
   │ 返回实际累计 θ（供调试日志）       │
   └──────────────────────────────────┘
```

> 其中 `r_turn` 为差速旋转等效半径标定值，δ 为补偿惯性过冲的提前量（建议 5°）。`Robot_UTurn180()` 与 `TurnLeft90` 流程相同，只是 θ_target 改为 180°。

| CJ-M49 三轴读取 | 静止 / X 朝下 / Y 朝下 三种姿态打印 ax,ay,az | 重力分量出现在对应轴 (~1g) |
| 静态零偏校准 | 调用 `IMU_Calibrate()` | 校准后静止读数 \|a\| ≤ 0.05 g |
| 角度积分 | 手动将小车旋转 90° / 180° | `IMU_GetYawDelta()` 累计误差 ≤ ±3° |

### 2.6.3 集成测试（L3）

| 场景 | 测试方法 | 验收 |
|------|----------|------|
| 直线走廊（远,0,0） | 1 m 直道 | 不撞墙，速度稳定 |
| 单 90° 左弯（远,1,0） | L 型走廊 | 角度误差 ≤ ±5° |
| 单 90° 右弯（远,0,1） | 镜像 L 型 | 同上 |
| 十字（远,1,1） | 十字路口（前方畅通） | 右手优先右转 |
| **死端口（近,0,0）** | **三面墙包围** | **以 ~15 cm 距离停止，原地 180° 掉头** |
| T 形左通（近,1,0） | T 型 + 前墙 | 左转 90° |
| T 形右通（近,0,1） | 镜像 T 型 | 右转 90° |
| T 形（近,1,1） | T 型 + 前墙 + 左右通 | 右手优先右转 |
| 连续 4 弯（回字） | 90° × 4 = 360° | 总角度误差 ≤ ±15°，不撞墙 |

### 2.6.4 系统测试（L4）

完整迷宫（含 ≥ 5 个路口 + ≥ 1 个死端口）连续测试：

| 项目 | 指标 | 测试次数 | 通过标准 |
|------|------|----------|----------|
| 通过率 | ≥ 80% | 5 | 至少 4 次成功 |
| 通过时间 | ≤ 3 min | 5 | 平均值 ≤ 3 min |
| 撞墙次数 | ≤ 1 次/局 | 5 | 平均值 ≤ 1 |
| 死端口识别 | 100% | 死端口出现次数统计 | 全部成功掉头 |
| 转弯角度误差 | ≤ ±5° | 每弯统计 | 平均值 ≤ ±5° |
| 连续运行 | ≥ 30 min | 1 | 期间无重启、无 I²C 错误、无超声波超时 |

### 2.6.5 异常 / 鲁棒性测试

| 异常 | 模拟方法 | 期望行为 |
|------|----------|----------|
| 单红外传感器损坏 | 拔下一路红外线 | 应停车或安全降级 |
| **HC-SR04 通信失败** | **拔下超声波模块** | **`US_GetDistanceMM()` 返回错误码；主循环回退到"仅左右红外"模式并串口报警** |
| **CJ-M49 I²C 通信失败** | **拔下 CJ-M49 数据线** | **转弯接口超时退回到固定延时备份方案，并通过串口报警** |
| 电池低电压 | 电压降至 6 V 以下 | 行为可降级但不应失控 |
| 上电时按键已按下 | 通电时按住 S1 | 不应误启动（应判断按键释放后才启动） |
| 强光环境 | 阳光直射红外/超声波 | 红外应能识别，超声波不受影响 |
| 软墙（吸声） | 用泡沫板做墙 | 超声波误差增大，验证软件容错 |
| CJ-M49 安装松动 | 故意松动固定螺丝 | 转弯精度下降但不应失控；震动加剧时串口打印异常加速度 |

### 2.6.6 验收测试（L5）

- 现场抽签迷宫布局；
- 至少完整跑 2 次，至少 1 次成功；
- 答辩问询 + 代码讲解 + 设计要点说明（重点讲解三传感器八状态决策、超声波死端口识别、IMU 闭环转弯如何共同保证精度）。

# 第三部分　预期目标与分工

## 3.1 预期目标

1. **基础目标（必达）：** 完成迷宫自主导航，5 次中至少 4 次成功通过；转弯角度误差 ≤ ±5°；死端口 100% 识别并自动 180° 掉头；
2. **进阶目标（争取）：** 增加灭火功能，到达指定灭火点报警；
3. **扩展目标（视进度）：** 通过 OLED 或额外通道实时显示三路传感器数据，便于演示。

## 3.3 风险与应对

| 风险 | 应对 |
|------|------|
| 转弯角度因电池电压下降而偏移 | CJ-M49 闭环判停天然抵消此问题（按角度而非时间停转） |
| CJ-M49 零偏温漂导致积分误差累计 | 每次按键启动前重新执行 200 ms 静态校准 |
| I²C2 总线偶发卡死 | 软件 watchdog 检测 + 总线复位序列 |
| 超声波回波串扰 | 限制采样周期 ≥ 60 ms + 中值滤波（3 点） |
| 超声波在斜墙下漏检 | T 形路口处依赖左右红外辅助判断；增加 2 帧确认机制 |
| 红外传感器受环境光干扰 | 调低检测距离、采用遮光罩 |
| 电机左右转速不一致致小车跑偏 | 标定左右轮 PWM 修正系数 |
| 车体震动耦合到加速度计 | CJ-M49 通过亚克力垫板刚性固定，软件加 5 点滑动平均 |
| PA11/PA12 USB 复用冲突 | 全部使用 CH340C / SWD 下载，不启用 USB |
| 迷宫墙壁反射率低（红外/超声同时弱） | 在墙面贴白色反光纸 + 适当软质（增强超声反射）|
