## 第一部分　总体方案设计

### 1.1 题目名称及简介

**题目名称：** 基于 STM32F103C8T6 的迷宫导航机器人设计（可拓展为迷宫灭火）

本课题以 STM32F103C8T6 微控制器（Blue Pill 核心板）为计算核心，以 STM32_10B 小车底板为外设载体，设计并实现一款能够在封闭迷宫环境中自主导航的差速轮式智能机器人。机器人通过"前向超声波 + 左右红外 + 三轴加速度计"复合感知系统实时获取环境信息，采用基于三路传感器的右手法则八状态决策算法进行路径选择，配合加速度计闭环反馈实现精确的 90°/180° 转弯控制，最终完成从迷宫入口自主行驶至出口的任务目标。

本课题融合了嵌入式 C 程序设计、I²C 总线通信、超声波测距与脉宽计时、PWM 调速、电机控制、惯性测量与角度积分等多项工程技术，具有较强的系统综合性。在完成基础迷宫导航的基础上，可进一步拓展为迷宫灭火任务：在指定灭火点检测到火焰信号后，机器人停车并触发蜂鸣器报警。

### 1.2 系统功能及指标设计

#### 1.2.1 系统功能设计

本系统需实现以下功能：

**一键启动**：机器人上电完成初始化与传感器零偏校准后，进入按键等待状态，用户按下 S1 按键后机器人开始自主导航，避免上电时意外启动。

**复合环境感知**：系统通过三类传感器构建完整的感知通道。左右红外避障传感器检测车体两侧 5～10 cm 范围内的墙壁状态，输出数字电平信号；HC-SR04 超声波模块持续测量前方障碍物距离，以 15 cm 为有墙/无墙判定阈值；CJ-M49 三轴加速度计在差速旋转过程中持续输出横向加速度分量，供控制层进行角速度估算与角度积分。

**右手法则自主导航**：依据前向超声波、左红外、右红外三路传感器的组合状态，识别直行走廊、左转路口、右转路口、T 形路口、十字路口和死端口共六类场景，执行对应的直行、左转 90°、右转 90°、掉头 180° 四类运动决策，实现右手始终贴墙的迷宫导航策略。

**加速度计闭环转弯**：转弯执行过程中以 10 ms 为步长循环读取加速度计数据，累计角速度积分直至到达目标角度（90° 或 180°），相较于固定延时的开环控制，对电池电压波动和地面摩擦差异具有较强的鲁棒性。

**死端口识别与掉头**：当前向距离小于等于 15 cm 且两侧均有墙时，系统判定为死端口，执行 180° 原地掉头。

**串口调试输出**：通过 USART1（PA9/PA10）经 CH340C 芯片向 PC 上报三路传感器读数、当前决策状态和累计转弯角度，辅助调试与数据记录。

**可选灭火功能**：在灭火点加入火焰传感器，检测到火焰后停车，蜂鸣器（PB0）鸣响并点亮 LED，模拟完成灭火动作。

#### 1.2.2 系统性能指标

迷宫通过成功率不低于 80%，以连续 5 次尝试中至少 4 次成功通过为验收依据。单次通过时间不超过 3 分钟，以按键按下至机器人到达出口的实测值计算。转弯角度误差不超过 ±5°，由加速度计闭环控制保障。前向超声波工作测距范围为 2～30 cm，在该区间内测距精度优于 ±5 mm；前墙判定阈值设定为 15 cm，可通过软件参数调整。红外侧墙检测距离为 5～10 cm，通过模块电位器现场标定。死端口识别成功率要求达到 100%，即机器人在三面封闭的场景下必须正确识别并完成掉头。加速度计静态零偏不超过 ±0.05 g，在上电后 200 ms 校准过程中完成修正。整机满电后持续工作时间不少于 30 分钟。

### 1.3 系统总体结构设计

本系统在硬件层面由控制层、感知层、执行层和电源层四个子系统构成。

**控制层**以 STM32F103C8T6 微控制器为核心，运行迷宫导航主程序。STM32_10B 小车底板作为外设载体，为各传感器和执行机构提供统一的物理接口与电源管理。MCU 内部配置 TIM4 提供四路 20 kHz PWM 输出控制电机、TIM2 提供 1 µs 分辨率计时基准用于超声波测距、I²C2 外设用于与加速度计通信、USART1 经 CH340C 芯片连接 PC 下载与调试。

**感知层**由三类传感器构成三个独立的感知通道：左/右红外避障传感器分别接载板 J3/J6 接口（PA11/PA12），检测车体两侧墙壁；HC-SR04 超声波模块接 P3 接口（TRIG = PB14，ECHO = PB15），检测前方障碍距离；CJ-M49 三轴加速度计接 P2 接口（SCL = PB10，SDA = PB11），通过 I²C2 总线提供转弯角度反馈。

**执行层**由 L298N 双路 H 桥驱动模块和两路减速直流电机构成。STM32 经 H2 排针引出 PB6/PB7（左电机正/反转 PWM）和 PB8/PB9（右电机正/反转 PWM）接入 L298N 的 IN1～IN4，L298N 的 OUT1/OUT2 驱动左电机，OUT3/OUT4 驱动右电机，通过左右轮差速实现全部运动模式。

**电源层**由小车底板内置电源管理电路承担。锂电池（7.4 V）经 A1117-3.3 LDO 稳压后为 MCU、红外传感器和 CJ-M49 加速度计提供 3.3 V；电池原始电压（VCCBAT）经 J5 接口直接供给 L298N，兼顾控制精度与驱动功率。整机共地，所有模块 GND 汇合至电池负极。

```text
                     │            电源层                 │
                     │  锂电池 7.4V                      │
                     │  ├─ A1117-3.3 → 3.3V (MCU/传感器)│
                     │  └─ VCCBAT → J5 → L298N (电机)   │
                     └─────────────────┬────────────────┘
                                       │
      ┌────────────────┐               ▼               ┌──────────────────┐
      │    感知层       │   ┌─────────────────────────┐ │    执行层         │
      │                │   │        控制层             │ │                  │
      │ 左红外 PA11   ─┼──▶│                         │─┼▶ L298N H桥       │
      │ 右红外 PA12   ─┼──▶│  STM32F103C8T6 (BluePill│ │  左电机 PB6/PB7  │
      │ 超声波 PB14/15─┼──▶│  72MHz / I²C2 / TIM2/4  │─┼▶ 右电机 PB8/PB9  │
      │ 加速度计PB10/11┼──▶│  USART1 / GPIO          │ │                  │
      │ 按键 PA15     ─┼──▶│                         │─┼▶ 蜂鸣器 PB0      │

                           │  右手法则八状态决策        │ └──────────────────┘
                           │  加速度计闭环转弯          │
```

系统上电后执行外设初始化，完成加速度计静态零偏校准（200 ms），随后进入按键等待。按键按下后进入主循环：每轮依次读取左右红外状态和前向超声波距离，送入三传感器八状态状态机，输出运动决策并调用对应的运动接口执行，直至到达出口。

## 第二部分　软硬件详细方案设计

### 2.1 传感器选型

本项目从课程提供的传感器套件中选用三类传感器，构成互补的复合感知体系。

#### 2.1.1 左/右红外避障传感器（侧墙感知，共 2 只）

红外避障传感器由红外发射管、光敏接收管与 LM393 电压比较器构成，工作电压 3.3～5 V，输出数字电平（DO）：前方 5～10 cm 范围内存在反射面时输出低电平（有墙），否则输出高电平（无墙），响应时间小于 1 ms。检测距离可通过板载电位器调节，与 STM32 的 GPIO 上拉输入直接相连，软件读取零额外开销。

选型理由：数字输出直接与 GPIO 对接，无需 ADC 资源；响应速度快，满足实时路口检测需求；检测距离可按迷宫通道宽度现场标定；与小车底板 J3（PA11）和 J6（PA12）接口定义完全吻合。

#### 2.1.2 HC-SR04 超声波测距模块（前向感知，1 只）

HC-SR04 基于 40 kHz 超声波收发原理进行测距，有效量程 2～400 cm，测距精度 ±3 mm，工作电压 5 V。STM32 向 TRIG 引脚发送不低于 10 µs 的高电平触发脉冲，模块随即发射超声波并将回波信号以脉冲宽度的形式从 ECHO 引脚输出，回波时长（µs）乘以 0.17 即得目标距离（mm）。本项目以 15 cm 为前墙/通道判定阈值，采用 TIM2（PSC=71，1 µs 分辨率）进行回波计时。

选型理由：提供精确的距离数值而非二值电平，可实现前向距离分级判断（畅通/接近/死端口）；不受环境光照和墙壁颜色影响，鲁棒性优于红外传感器；与小车底板 P3 接口（PB14/PB15）定义完全一致，无需改板。

#### 2.1.3 CJ-M49 三轴数字加速度计（转弯角度反馈，1 只）




选型理由：I²C 接口仅占 2 根引脚（PB10/PB11），配置灵活；三轴同步输出，便于横向加速度合成；配合 200 ms 静态零偏校准，单次 90°/180° 转弯角度误差可控制在 ±5° 以内；与小车底板 P2 接口（PB10 = I²C2_SCL，PB11 = I²C2_SDA）直接兼容。

### 2.2 系统硬件连接图

Blue Pill 核心板插入小车底板 SK1 插座，通过 2×20 排针实现全引脚互联。各外设的物理连接关系如下所述。

左红外传感器经三针线连接 J3 接口（VCC 接 3.3 V，GND 接地，DO 接 PA11）；右红外传感器经三针线连接 J6 接口（DO 接 PA12）。HC-SR04 超声波模块经四针线连接 P3 接口，其中 VCC 接载板 5 V，TRIG 接 PB14（GPIO 推挽输出），ECHO 接 PB15（GPIO 浮空输入，配合 TIM2 计时），GND 接地。CJ-M49 加速度计经四针线连接 P2 接口，VCC 接 3.3 V，SCL 接 PB10（I²C2_SCL，复用开漏输出），SDA 接 PB11（I²C2_SDA，复用开漏输出），GND 接地；若模块未内置上拉电阻，需在 SCL/SDA 线上各加 4.7 kΩ 上拉电阻至 3.3 V。

L298N 电机驱动模块通过 H2 排针引出线与 STM32 相连：IN1 接 PB6（TIM4_CH1，左电机正转 PWM），IN2 接 PB7（TIM4_CH2，左电机反转 PWM），IN3 接 PB8（TIM4_CH3，右电机正转 PWM），IN4 接 PB9（TIM4_CH4，右电机反转 PWM）；ENA 与 ENB 通过跳线接高电平常使能；电源端（VS）经 J5 接口由电池 VCCBAT（≈7.4 V）直接供电；OUT1/OUT2 驱动左电机，OUT3/OUT4 驱动右电机。

S1 按键接 PA15（GPIO 上拉输入，按下为低电平）；蜂鸣器 BUZ1 经 SS8050 三极管驱动，控制引脚为 PB0；调试串口经 CH340C 将 PA9（USART1 TX）和 PA10（USART1 RX）转换为 USB 接口与 PC 连接，配合载板内置的一键自动下载电路，无需手动拨动 BOOT0 跳线。SWD 接口（PA13/PA14）支持 ST-Link 在线调试。

```text
            ║                STM32_10B 小车底板                       ║
            ║                                                          ║
            ║   ┌──────────────────────────────────┐                  ║
左红外────────╬──▶ J3 [PA11]                        │                  ║
右红外────────╬──▶ J6 [PA12]                        │  STM32F103C8T6  │  ║
HC-SR04───────╬──▶ P3 [PB14=TRIG, PB15=ECHO, 5V]   │  (Blue Pill)    │  ║
CJ-M49────────╬──▶ P2 [PB10=SCL, PB11=SDA, 3.3V]   │                 │  ║
            ║   │   S1 [PA15]  BUZ1 [PB0] PC13     └──────────────────┘  ║
            ║   │   CH340C → PA9/PA10 (USART1)                        ║

            ║   │   BT1 → 锂电池 7.4V                                  ║        │
```

> **引脚冲突说明：** Blue Pill 板载 USB D-/D+ 默认占用 PA11/PA12，与本项目红外传感器输入冲突，因此系统下载与调试必须通过载板 CH340C 串口或 SWD 接口完成，不可同时启用 Blue Pill 原生 USB。P2 接口底层引脚 PB10/PB11 同时具备 USART3 和 I²C2 复用功能，本项目通过软件配置为 I²C2 主机模式，无需硬件改动。

### 2.3 编程环境及其设置

本项目采用 **STM32CubeIDE v1.14**（或 Keil MDK-ARM v5 + STM32CubeMX）作为集成开发环境，配合 **STM32CubeF1 HAL 库（STM32F1xx HAL Driver v1.1.9）** 进行开发。

**工具链安装**：安装 STM32CubeIDE（内置 STM32CubeMX、ARM GCC 工具链与 ST-Link 驱动）；若使用 Keil，需额外安装 STM32F1xx DFP 芯片支持包并从 STM32CubeMX 导出 MDK-ARM 工程。通过 USB 串口下载时安装 CH340C 驱动（CH341SER.exe），配合 STM32CubeProgrammer 完成烧录；ST-Link 调试驱动已内置于 STM32CubeIDE。

**STM32CubeMX 时钟与外设配置**：芯片选型 STM32F103C8Tx，RCC 选 HSE Crystal/Ceramic Resonator（8 MHz 外部晶振），HCLK 配置为 72 MHz（PLL 9 倍频）；APB1 预分频 /2（PCLK1 = 36 MHz，供 I²C2 与 TIM4），APB2 不分频（PCLK2 = 72 MHz，供 USART1）。外设配置：TIM2 时基模式，PSC = 71、ARR = 0xFFFF，分辨率 1 µs，供超声波回波计时，使用 `HAL_TIM_Base_Start` 后直接读取 `__HAL_TIM_GET_COUNTER`；TIM4 PWM Generation CH1～CH4，PSC = 35、ARR = 99，输出频率 20 kHz，通过 `__HAL_TIM_SET_COMPARE` 设置占空比（0～99 对应 0%～100%）；I²C2 Fast Mode 400 kHz，用于 CJ-M49 通信，调用 `HAL_I2C_Mem_Read/Write`；USART1 波特率 115200，调用 `HAL_UART_Transmit` 输出调试信息；所有 GPIO 由 CubeMX 自动生成初始化代码。

**工程关键配置**：编译预处理宏定义为 `USE_HAL_DRIVER` 与 `STM32F103xB`（由 CubeMX 自动写入）。工程自动包含 `stm32f1xx_hal_rcc.c`、`stm32f1xx_hal_gpio.c`、`stm32f1xx_hal_tim.c`、`stm32f1xx_hal_uart.c`、`stm32f1xx_hal_i2c.c` 等 HAL 驱动源文件及 `stm32f1xx_it.c` 中断服务程序文件；用户代码写在 CubeMX 生成的 `/* USER CODE BEGIN */` / `/* USER CODE END */` 区段内，重新生成工程时不会被覆盖。Debug 配置选 ST-Link GDB Server、SWD 接口；Run/Flash 配置勾选 Reset and Run。启用 Newlib Nano（`--specs=nano.specs`）以减小 `printf` 体积，编译优化取 `-O1`。

### 2.4 应用软件功能模块划分及其框图

系统软件按分层设计原则划分为驱动层、算法层和应用层三个层次。

**驱动层**提供与硬件直接交互的底层接口，共六个子模块。`PWM.c` 封装 TIM4 初始化及四通道占空比设置函数；`Motor.c` / `robot.c` 在 PWM 驱动基础上封装前进、后退、差速旋转、停止等运动原语；`Irobstacle.c` 封装 PA11/PA12 的 GPIO 读取，提供 `IR_GetLeft()` 和 `IR_GetRight()` 两个接口；`Ultrasonic.c` 实现基于 TIM2 微秒计时的 HC-SR04 测距逻辑，对外暴露 `US_GetDistanceMM()` 和 `US_IsFrontWall()` 接口；`IMU.c` 实现 I²C2 通信、CJ-M49 寄存器配置、静态零偏校准以及角速度积分，对外暴露 `IMU_Calibrate()`、`IMU_ReadAccel()` 和 `IMU_GetYawDelta()` 接口；`Key.c` 实现 PA15 按键消抖与状态读取。

**算法层**包含两个核心模块。`maze.c` 实现三传感器八状态右手法则状态机：读取前向超声波（F：距离 ≤ 15 cm 记为近）、左红外（L：0 有墙）、右红外（R：0 有墙）的组合状态，按八种情况映射到直行、左转 90°、右转 90°、掉头 180° 四类决策。`turn.c` 实现加速度计闭环转弯：以 10 ms 为步长循环读取 CJ-M49 的横向加速度合量，估算瞬时角速度并积分，待累计角度达到目标值（90° 或 180°）减去补偿量（约 5°）后停止 PWM，再执行约 150 mm 的盲走进廊动作，防止在路口豁口处误读传感器。

**应用层**即 `main.c`，完成外设初始化、加速度计零偏校准、按键等待，随后进入主循环，依次读取三路传感器、送入状态机决策、调用运动接口执行，形成完整的"感知—决策—执行"闭环。

```text

│                       应用层  main.c                                │
│   初始化 → 零偏校准 → 按键等待 → while(1){感知 → 决策 → 执行}      │
└────────────────────────────┬────────────────────────────────────────┘
                             │ 调用
          ┌──────────────────┼────────────────────┐
          ▼                  ▼                    ▼
┌─────────────────┐  ┌──────────────────┐  ┌────────────────────────┐
│    算法层        │  │    算法层         │  │       驱动层            │
```

### 2.5 开发调试步骤与时间安排

本课程设计按照"需求分析 → 硬件搭建 → 环境搭建 → 驱动开发 → 算法集成与标定 → 完整迷宫调试 → 扩展功能 → 验收与报告"八个阶段依次推进，共四周。

**第一阶段（第 1 周前段）** 完成需求分析与方案确定：明确迷宫导航任务目标，选定右手法则八状态复合感知方案，确定验收标准（5 次 4 次通过、单次 < 3 min、转弯精度 ±5°），形成总体方案文档并通过开题评审。

**第二阶段（第 1 周中段）** 完成硬件搭建与连接：将 Blue Pill 插入底板，依次连接左/右红外传感器（J3/J6）、HC-SR04 超声波（P3）、CJ-M49 加速度计（P2）及 L298N 电机驱动（H2 + J5）；HC-SR04 安装在车头正前方中心、探头中轴线与前进方向一致，CJ-M49 刚性安装在底盘几何中心并保持水平正置；整机共地，万用表通断检查无短路。验收：通电后 LED1 亮、PC13 LED 闪烁，整机电流小于 250 mA。

**第三阶段（第 1 周末）** 搭建开发环境：安装 Keil MDK、STM32F1 DFP 包、CH340C 驱动，配置时钟树（72 MHz），使能 TIM2/TIM4/I²C2/USART1，编写 PC13 LED 闪烁最小工程验证工具链。验收：编译 0 错误，LED 以 1 Hz 闪烁。

**第四阶段（第 2 周前段）** 完成基础驱动开发与单元测试：逐模块开发 PWM 驱动（示波器验证 20 kHz 方波）、电机正反转（单轮上电验证）、红外读取（手遮观察串口）、超声波测距（直尺标定 5～200 mm 区间误差 ≤ ±5 mm）、加速度计 I²C 通信与角度积分（旋转 90° 后串口打印累计 θ 误差 ≤ ±3°）、按键消抖。

**第五阶段（第 2 周后段）** 完成算法集成与标定：在 `main.c` 中实现三传感器八状态状态机，对接 IMU 闭环转弯接口，标定超声波有效范围与旋转半径参数（`TURN_RADIUS`），在直线 + 单弯 + 死端口的简易模拟迷宫中验证全部八种场景均能正确响应。验收：单弯迷宫一次通过，转弯误差 ≤ ±5°，死端口正确掉头。

**第六阶段（第 3 周前段）** 完整迷宫调试与调参：搭建包含全部路口类型的标准迷宫，针对偏行（调整左右轮速）、前墙误判（调整 `FRONT_WALL_MM` 阈值或加 3 次确认）、转弯不足或过冲（调整 `TURN_GUARD_DEG`）、撞墙（降低前进速度或提高红外灵敏度）等问题逐一排查，每次测试记录成功率、转弯实测角度和前墙判定距离，直至连续 5 次尝试成功率不低于 80%。

**第七阶段（第 3 周中段，选做）** 集成灭火扩展功能：火焰传感器 DO 接入空闲 GPIO，主循环中检测火焰电平，检测到时停车并触发蜂鸣器与 LED 报警，要求在灭火点 3 秒内响应。

**第八阶段（第 3 周末至第 4 周）** 验收与报告撰写：准备至少 2 次完整跑迷宫演示（含至少 1 次死端口掉头），整理硬件接线图、软件流程图、传感器标定记录、调参记录和测试数据，提交课程设计报告与答辩 PPT，通过现场演示与答辩。

### 2.6 系统测试方案

测试分三个层次推进：首先对 PWM、电机、红外、超声波（测距误差 ≤ ±5 mm）、加速度计（90° 积分误差 ≤ ±3°）逐模块单元验证；随后在直线、单弯、十字、死端口等简易场景中集成测试，确认八种决策状态全部正确响应；最终在 1.5 m × 1.5 m 标准迷宫中进行整机验收，连续 5 次测试通过率不低于 80%、单次完成时间不超过 3 分钟、全程不碰墙，同时验证低电压与强光等异常工况下的鲁棒性。
