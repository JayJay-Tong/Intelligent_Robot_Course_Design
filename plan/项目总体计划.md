# 智能机器人课程设计项目总体计划

## 项目概述

| 项目名称 | 基于STM32F103C8T6的迷宫机器人（含灭火功能） |
|----------|---------------------------------------------|
| 主控芯片 | STM32F103C8T6（Blue Pill） |
| 驱动方式 | L298N驱动双路无编码器减速直流电机 |
| 传感器   | 前方左右各一个红外避障传感器 |
| 核心功能 | 走迷宫 / 迷宫灭火（到达迷宫灭火点） |
| 开发环境 | Keil MDK + STM32标准外设库 |

---

## 项目目标

1. 实现智能机器人在迷宫中的自主导航（走迷宫）；
2. 可选扩展：识别迷宫内灭火点（火焰传感器），到达并完成灭火动作；
3. 完成课程规定的作业一、作业二及课程设计报告。

## 各阶段详细计划

### 第一阶段：任务理解与初步设计（第1周前半段）

**目标：**
- 理解课程设计任务书要求；
- 确定题目（迷宫导航 或 迷宫灭火）；
- 完成初步方案设计与组内分工。

**工作内容：**
1. 阅读任务书精简版，明确选题（走迷宫 + 灭火扩展）；
2. 学习STM32F103C8T6硬件原理图、扩展板原理图、L298N电机驱动原理图；
3. 了解示例代码结构（PWM驱动、红外传感器读取、机器人运动控制）；
4. 明确分工，制定开发计划；
5. 完成**作业一**（文献综述 + 系统分析）；
6. 开始准备**作业二**总体方案设计。

**产出：**
- 方案设计初稿（题目、功能、指标）
- 作业一文档

---

### 第二阶段：硬件测试与传感器标定（第1~2周）

**目标：**
- 验证硬件各模块功能正常；
- 确定传感器参数。

**工作内容：**

| 测试项目 | 测试内容 | 验收标准 |
|----------|----------|----------|
| 电机驱动测试 | TIM4 PWM输出，控制左右电机转速和方向 | 电机能正转、反转、调速 |
| 红外传感器测试 | PA11（左）、PA12（右）读取障碍物检测信号 | 检测到障碍时返回0，无障碍返回1 |
| 按键测试 | 按键触发机器人启动 | 按键按下后机器人开始运动 |
| OLED显示测试（可选） | 显示传感器状态和运动状态 | 能正确显示信息 |
| 整车联调 | 电机+传感器+控制逻辑联合测试 | 小车能根据传感器信号做出正确响应 |

**注意事项：**
- 左电机控制：TIM4_CH1（PB6，前进）、TIM4_CH2（PB7，后退）
- 右电机控制：TIM4_CH3（PB8，前进）、TIM4_CH4（PB9，后退）
- 红外传感器：检测到障碍物输出低电平（0），无障碍输出高电平（1）

---

### 第三阶段：避障基础功能实现（第2周）

**目标：**
- 实现基于双红外传感器的实时避障行驶。

**核心逻辑（参考示例代码）：**

```
左传感器=1, 右传感器=1  → 前进
左传感器=1, 右传感器=0  → 右转（右侧有障碍）
左传感器=0, 右传感器=1  → 左转（左侧有障碍）
左传感器=0, 右传感器=0  → 制动+原地右转（正前方有障碍）
```

**工作内容：**
1. 基于`main.c`示例代码完善避障逻辑；
2. 调整PWM速度值（建议前进速度60~80/100），避免惯性过大；
3. 调整转向时间参数，使机器人能稳定转向而不偏移过大；
4. 在空旷环境测试避障功能。

---

### 第四阶段：迷宫导航算法开发（第2~3周）

**目标：**
- 实现在迷宫中自主导航到达出口（或灭火点）。

**算法选择：右手法则（推荐）**

> 机器人始终保持右手贴墙行驶，遇到路口优先向右转。

**迷宫走廊感知逻辑：**

> 迷宫中正常行驶时左右两侧均有墙壁（两传感器均检测到障碍）；当某一侧墙壁消失时，说明该侧出现路口，应向该侧转弯。

```
状态0: 左=有墙, 右=有墙 → 直行（正常走廊）
状态1: 左=无墙, 右=有墙 → 左转（左侧出现路口）
状态2: 左=有墙, 右=无墙 → 右转（右侧出现路口）
状态3: 左=无墙, 右=无墙 → 右转（T形或十字路口，优先右转）
```

**工作内容：**
1. 设计迷宫导航状态机；
2. 实现转弯角度控制（通过延时时间控制转弯角度，需调参）；
3. 在模拟迷宫中测试和调参；
4. 记录测试数据，为报告提供实验依据。

**灭火功能扩展（可选）：**
- 增加火焰传感器读取模块；
- 检测到火焰时执行停止动作（模拟灭火）；
- 在到达灭火点后触发灭火指示（LED / 蜂鸣器）。

---

### 第五阶段：系统集成与调试（第3~4周）

**目标：**
- 完成完整迷宫机器人系统，通过验收测试。

**工作内容：**
1. 集成所有功能模块（运动控制 + 避障 + 迷宫导航 + 可选灭火）；
2. 进行完整迷宫测试，记录成功率；
3. 参数精调：
   - 前进速度（建议：60~80）
   - 转弯速度（建议：60~70）
   - 转弯时间（根据实测调整，约300~600ms）
   - 检测距离调整（红外传感器灵敏度旋钮）；
4. 完成**作业二**所有内容（含开题答辩PPT）；
5. 撰写课程设计报告初稿。

**验收标准：**
- 机器人能独立在迷宫中行驶，找到出口；
- 不碰撞迷宫墙壁；
- 可选：在灭火点停止并发出信号。

---

### 第六阶段：验收与报告撰写（第4周）

- 通过正式验收，提交完整的课程设计报告。

2. 分析实验结果，总结问题与解决方案；
3. 完善课程设计报告（按报告模板要求）：

4. 提交报告。

## 关键风险与应对

| 风险 | 可能影响 | 应对措施 |
|------|----------|----------|
| 电机无编码器，转弯角度难以精确控制 | 迷宫导航不稳定 | 依赖延时控制，在具体迷宫中反复调参 |
| 红外传感器只有左右两个，无前向检测 | 无法提前检测正前方障碍 | 利用两传感器均触发逻辑判断正前方障碍 |
| 迷宫结构不同导致参数需重调 | 换迷宫后失效 | 尽早获取实际迷宫尺寸，针对性调参 |
| 代码注释为乱码（GBK编码） | 可读性差 | 重新添加UTF-8注释，不影响功能 |
