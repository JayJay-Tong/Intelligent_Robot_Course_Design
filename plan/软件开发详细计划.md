# 软件开发详细计划

## 软件架构概述

本项目软件基于STM32标准外设库（SPL）开发，采用前后台裸机架构，主循环轮询传感器状态并执行运动控制逻辑。

```
软件模块结构：
├── User/
│   ├── main.c          # 主程序，迷宫导航逻辑
│   ├── stm32f10x_conf.h
│   └── stm32f10x_it.c  # 中断服务程序
├── Hardware/
│   ├── PWM.c / .h      # TIM4 PWM初始化
│   ├── robot.c / .h    # 运动控制（前进/后退/转向）
│   ├── Irobstacle.c/.h # 红外传感器读取
│   ├── Key.c / .h      # 按键输入
│   ├── LED.c / .h      # LED状态指示
│   └── OLED.c / .h     # OLED显示（可选调试）
└── System/
    ├── Delay.c / .h    # 延时函数
    └── [STM32标准库]   # RCC/GPIO/TIM等
```

## 模块详细设计

### 1. PWM电机驱动模块（PWM.c）

**功能：** 初始化TIM4，输出4路PWM信号控制L298N电机驱动器。

**硬件映射：**
| PWM通道 | GPIO引脚 | 连接 | 功能 |
|---------|---------|------|------|
| TIM4_CH1 | PB6 | L298N IN1 | 左电机正转 |
| TIM4_CH2 | PB7 | L298N IN2 | 左电机反转 |
| TIM4_CH3 | PB8 | L298N IN3 | 右电机正转 |
| TIM4_CH4 | PB9 | L298N IN4 | 右电机反转 |

**参数配置：**
- 时钟：APB1 = 36MHz → TIM4时钟 = 72MHz
- 预分频：36-1，计数时钟 = 2MHz
- 自动重装值：100-1，PWM频率 = 20kHz
- 占空比范围：0~100（对应0%~100%）

**接口函数：**
```c
void PWM_Init(void);  // 初始化TIM4 PWM
```

---

### 2. 机器人运动控制模块（robot.c）

**功能：** 封装L298N四路PWM控制，提供高层运动接口。

**接口函数：**

| 函数名 | 参数 | 功能 |
|--------|------|------|
| `robot_Init()` | 无 | 初始化 |
| `robot_speed(l1,l2,r1,r2)` | 0~100 | 直接设置四路PWM占空比 |
| `makerobo_run(speed, time)` | speed:0~100, time:ms | 前进 |
| `makerobo_back(speed, time)` | speed:0~100, time:ms | 后退 |
| `makerobo_Left(speed, time)` | speed:0~100, time:ms | 左转（右轮驱动） |
| `makerobo_Right(speed, time)` | speed:0~100, time:ms | 右转（左轮驱动） |
| `makerobo_Spin_Left(speed, time)` | speed:0~100, time:ms | 原地左转 |
| `makerobo_Spin_Right(speed, time)` | speed:0~100, time:ms | 原地右转 |
| `makerobo_brake(time)` | time:ms | 制动停止 |

**运动逻辑说明：**
- 前进：left1_speed=speed, left2_speed=0, right1_speed=speed, right2_speed=0
- 后退：left1_speed=0, left2_speed=speed, right1_speed=0, right2_speed=speed
- 左转：左轮停，右轮驱动（left1=0, right1=speed）
- 右转：右轮停，左轮驱动（left1=speed, right1=0）
- 原地左转：左轮后退，右轮前进
- 原地右转：左轮前进，右轮后退

### 3. 红外传感器模块（Irobstacle.c）

**功能：** 读取左右红外传感器信号。

**硬件映射：**
| 传感器 | GPIO引脚 | 信号逻辑 |
|--------|---------|---------|
| 左红外传感器 | PA11 | 0=检测到障碍，1=无障碍 |
| 右红外传感器 | PA12 | 0=检测到障碍，1=无障碍 |

**接口函数：**
```c
void Irobstacle_Init(void);         // GPIO初始化（上拉输入）
uint8_t Left_Irobstacle_Get(void);  // 读取左传感器
uint8_t Right_Irobstacle_Get(void); // 读取右传感器
```

---

### 4. 迷宫导航主逻辑（main.c）

**算法：右手法则（Wall Following - Right Hand Rule）**

**状态转换表：**

> 迷宫中正常行驶时左右两侧均有墙壁，传感器输出0（有障碍）；当某侧墙壁消失，即出现路口，应向该侧转弯。

| 左传感器 | 右传感器 | 动作 | 含义 |
|---------|---------|------|------|
| 0（有墙） | 0（有墙） | 前进 | 正常走廊，两侧有墙 |
| 1（无墙） | 0（有墙） | 左转400ms | 左侧出现路口，向左转入 |
| 0（有墙） | 1（无墙） | 右转400ms | 右侧出现路口，向右转入 |
| 1（无墙） | 1（无墙） | 右转400ms | T形/十字路口，优先右转 |

**主程序流程图：**

```text
开始
  │
  ▼
初始化（robot_Init, Key_Init, Irobstacle_Init）
  │
  ▼
等待按键按下（启动信号）
  │
  ▼
┌─────────────────────────────────────────────────┐
│              主循环 while(1)                      │
│                                                 │
│   读取左传感器 L = Left_Irobstacle_Get()          │
│   读取右传感器 R = Right_Irobstacle_Get()         │
│                                                 │
│   L=0, R=0 ──→ makerobo_run(70, 0)   // 直行   │
│   L=1, R=0 ──→ makerobo_Left(70, 400) // 左转  │
│   L=0, R=1 ──→ makerobo_Right(70,400) // 右转  │
│   L=1, R=1 ──→ makerobo_Right(70,400) // 右转  │
└─────────────────────────────────────────────────┘
```

## 调参指南

### 速度参数调整

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 前进速度 | 60~80 | 过快则传感器反应不及时，过慢则效率低 |
| 转弯速度 | 60~70 | 与前进速度接近，保持稳定性 |
| 原地旋转速度 | 65~75 | 用于180°掉头，注意不要过快导致打滑 |

### 时间参数调整

| 参数 | 初始值 | 调整方法 |
|------|--------|----------|
| 转弯时间 | 400ms | 在直道上测试，调整到转弯约90° |
| 掉头旋转时间 | 900ms | 测试到旋转约180° |
| 制动时间 | 400ms | 保证车体停稳后再执行转向 |

### 红外传感器灵敏度

- 传感器板上有蓝色电位器，顺时针旋转增大检测距离；
- 建议检测距离调整为 5~10cm；
- 在白色迷宫墙壁背景下测试效果最佳。

## 可选功能：灭火扩展

### 火焰传感器集成

**硬件：** 火焰传感器模拟输出接ADC通道（如PA0），或数字输出接GPIO。

**软件逻辑：**
```c
// 在主循环中增加火焰检测
if (Flame_Detected()) {
    makerobo_brake(500);   // 停车
    LED_On();              // 亮灯指示（模拟灭火）
    Delay_ms(2000);        // 停留2秒
    LED_Off();
    // 可继续导航或停止
}
```

## 开发调试步骤

1. **单模块测试：** 分别测试PWM、传感器、按键，确认各模块独立工作正常；
2. **运动控制测试：** 测试前进、转弯、制动功能，调整速度参数；
3. **避障基础测试：** 在直线走廊中测试避障逻辑，确认传感器信号正确响应；
4. **迷宫适配测试：** 在模拟迷宫中测试，逐步调整转弯时间；
5. **完整迷宫测试：** 进行完整迷宫路径测试，记录成功率；
6. **灭火功能测试（可选）：** 集成火焰传感器，测试检测和停车功能。

## 代码规范

- 函数命名：驼峰式（`makerobo_run`）或下划线分隔（`robot_speed`）
- 所有硬件初始化在`main()`开头完成
- 关键参数（速度、时间）使用`#define`宏定义，便于统一调整
- 注释使用中文，说明函数功能和参数含义
